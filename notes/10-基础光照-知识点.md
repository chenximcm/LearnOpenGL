## 1. Phong 光照模型概述

### 1.1 三个分量

Phong 光照模型将光照分解为三个独立分量：

```
最终颜色 = (环境光 + 漫反射 + 镜面反射) × 物体颜色
```

| 分量 | 现象 | 直观理解 |
|------|------|---------|
| **Ambient**（环境光） | 物体的基本可见度 | 室内无处不在的微弱环境光 |
| **Diffuse**（漫反射） | 面向光源的面亮，背光面暗 | 手电筒直照 vs 斜照 |
| **Specular**（镜面反射） | 光滑表面的高光亮点 | 金属、塑料表面的反光 |

### 1.2 与颜色章节的关系

在颜色章节中，我们的公式是：

```
Perceived = LightColor × ObjectColor
```

基础光照将其扩展为：

```
Perceived = (Ambient + Diffuse + Specular) × ObjectColor
```

其中 Ambient、Diffuse、Specular 都是从 LightColor 派生出来的。

## 2. 环境光（Ambient）

### 2.1 作用

环境光确保物体的**背光面不会完全漆黑**。即使在没有直接光源照射的区域，物体仍然可见。

### 2.2 公式

```cpp
vec3 ambient = ambientStrength * lightColor;
```

- `ambientStrength`：环境光强度（通常取 0.01 ~ 0.2）
- `lightColor`：光源颜色

### 2.3 特点

- 与法线方向**无关**
- 与光线方向**无关**
- 是一个**常数**乘以光源颜色
- 值太大（>0.3）会使场景看起来"发灰"

---

## 3. 漫反射（Diffuse）

### 3.1 作用

模拟光线照射到粗糙表面后的**均匀反射**。这是光照模型中最重要的分量，它让 3D 物体产生立体感。

### 3.2 公式

```cpp
vec3 norm = normalize(Normal);                        // 归一化法线
vec3 lightDir = normalize(lightPos - FragPos);        // 从片段指向光源
float diff = max(dot(norm, lightDir), 0.0);           // 角度系数 [0, 1]
vec3 diffuse = diff * lightColor;                     // 漫反射分量
```

### 3.3 关键理解

**法线与光线的夹角决定漫反射强度：**

```
dot(normal, lightDir) > 0  → 表面面向光源 → 亮
dot(normal, lightDir) = 0  → 表面与光线平行 → 暗
dot(normal, lightDir) < 0  → 表面背对光源 → 无光（被 max 截断为 0）
```

### 3.4 为什么用 `max(dot(...), 0)`？

- 当法线背对光源时，点积为负值
- 负值没有物理意义（背光面不应该产生漫反射）
- 用 `max(x, 0)` 将负值截断为 0

---

## 4. 镜面反射（Specular）

### 4.1 作用

模拟光滑表面上的**高光亮点**（如金属、塑料、玻璃的反光）。

### 4.2 公式

```cpp
vec3 viewDir = normalize(viewPos - FragPos);          // 片段指向摄像机
vec3 reflectDir = reflect(-lightDir, norm);           // 反射方向
float spec = pow(max(dot(viewDir, reflectDir), 0.0), shininess); // 高光系数
vec3 specular = specularStrength * spec * lightColor; // 镜面反射分量
```

### 4.3 反光度（Shininess）

`shininess` 控制高光的**范围大小**：

| 反光度 | 高光范围 | 模拟表面 |
|--------|---------|---------|
| 8 | 宽大 | 粗糙表面（木头、布料） |
| 32 | 适中 | 塑料 |
| 128 | 窄小 | 金属 |
| 256 | 极小 | 镜面 |

**直观理解**：shininess 是 `pow()` 的指数，指数越大，dot 结果的衰减越快——只有视线完全对齐反射方向时才有高光。

## 5. 法线（Normal）

### 5.1 什么是法线？

法线是**垂直于表面的单位向量**。对于立方体：

| 面 | 法线 |
|----|------|
| 正面（Z+） | (0, 0, 1) |
| 背面（Z-） | (0, 0, -1) |
| 右面（X+） | (1, 0, 0) |
| 左面（X-） | (-1, 0, 0) |
| 顶面（Y+） | (0, 1, 0) |
| 底面（Y-） | (0, -1, 0) |

### 5.2 法线矩阵（Normal Matrix）

法线**不能直接用 model 矩阵变换**：

```
model 矩阵对顶点进行非均匀缩放时，
法线方向会被破坏（不再垂直于表面）。
```

**正确做法**：用法线矩阵（model 矩阵的逆转置矩阵的 3×3 部分）

```glsl
// 顶点着色器中
Normal = mat3(transpose(inverse(model))) * aNormal;
```

> ⚠️ `inverse()` 是昂贵的操作。在性能敏感的场合应该在 CPU 端计算并传入 uniform。

### 5.3 必须归一化

法线在顶点着色器变换后，**必须在片段着色器中重新归一化**：

```glsl
// 片段着色器中
vec3 norm = normalize(Normal);
```

这是因为插值后的法线不再是完美的单位向量，长度可能发生变化。

## 6. 顶点数据的变化

### 6.1 数据格式对比

| 章节 | 顶点格式 | Stride |
|------|---------|-------|
| 坐标系统 / 摄像机 | `[位置 (3) | 纹理坐标 (2)]` | 20 字节 |
| 颜色 / Colors | `[位置 (3) | 纹理坐标 (2)]` | 20 字节 |
| **基础光照 / Basic Lighting** | `[位置 (3) | **法线 (3)** | 纹理坐标 (2)]` | **32 字节** |

### 6.2 VAO 属性设置

```cpp
// 位置属性 (location = 0) — 3 floats
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 8 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);

// 法线属性 (location = 1) — 3 floats, offset 12
glVertexAttribPointer(1, 3, GL_FLOAT, GL_FALSE, 8 * sizeof(float), (void*)(3 * sizeof(float)));
glEnableVertexAttribArray(1);

// 纹理坐标属性 (location = 2) — 2 floats, offset 24
glVertexAttribPointer(2, 2, GL_FLOAT, GL_FALSE, 8 * sizeof(float), (void*)(6 * sizeof(float)));
glEnableVertexAttribArray(2);
```

### 6.3 光源 VAO 不变

光源标记的着色器（`light_cube.vert`）只需要位置属性，所以 lightVAO 只启用 `location = 0`：

```cpp
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 8 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
```

## 7. 着色器实现

### 7.1 顶点着色器 `basic_lighting.vert`

```cpp
#version 330 core

layout (location = 0) in vec3 aPos;
layout (location = 1) in vec3 aNormal;
layout (location = 2) in vec2 aTexCoord;

out vec3 FragPos;       // 片段在世界空间的位置（给片段着色器用）
out vec3 Normal;        // 世界空间的法线
out vec2 TexCoord;

uniform mat4 model;
uniform mat4 view;
uniform mat4 projection;

void main()
{
    FragPos = vec3(model * vec4(aPos, 1.0));
    Normal = mat3(transpose(inverse(model))) * aNormal;
    TexCoord = aTexCoord;
    gl_Position = projection * view * model * vec4(aPos, 1.0);
}
```

### 7.2 片段着色器 `basic_lighting.frag` — Phong 模型

```cpp
#version 330 core
out vec4 FragColor;

in vec3 FragPos;
in vec3 Normal;
in vec2 TexCoord;

uniform vec3 lightPos;
uniform vec3 lightColor;
uniform vec3 viewPos;
uniform vec3 objectColor;
uniform sampler2D texture1;
uniform bool useTexture;

uniform float ambientStrength;
uniform float specularStrength;
uniform float shininess;

void main()
{
    // 1. 环境光
    vec3 ambient = ambientStrength * lightColor;

    // 2. 漫反射
    vec3 norm = normalize(Normal);
    vec3 lightDir = normalize(lightPos - FragPos);
    float diff = max(dot(norm, lightDir), 0.0);
    vec3 diffuse = diff * lightColor;

    // 3. 镜面反射
    vec3 viewDir = normalize(viewPos - FragPos);
    vec3 reflectDir = reflect(-lightDir, norm);
    float spec = pow(max(dot(viewDir, reflectDir), 0.0), shininess);
    vec3 specular = specularStrength * spec * lightColor;

    // 4. 合成
    vec3 lighting = (ambient + diffuse + specular) * objectColor;

    if (useTexture) {
        vec4 texColor = texture(texture1, TexCoord);
        FragColor = vec4(lighting * texColor.rgb, 1.0);
    } else {
        FragColor = vec4(lighting, 1.0);
    }
}
```

## 9. 常见问题

### Q1：为什么我的物体没有光照效果，看起来是纯色的？

检查是否正确传入了 `lightPos`、`lightColor`、`viewPos` 等 uniform。最常见的问题：
- 忘记调用 `shader.use()` 就设置 uniform
- uniform 名称拼写与着色器中的不一致
- 法线数据不正确（所有法线都是 (0,0,0)）

### Q2：为什么高光位置不对或不显示？

可能原因：
- `viewPos` 没有更新（摄像机移动后要重新传入）
- `reflectDir` 计算错误（注意 `reflect()` 的第一个参数是 `-lightDir`，因为 lightDir 指向光源，反射需要从光源出发的方向）
- `shininess` 太小，高光范围太大看起来像没有
- 法线方向错误

### Q3：为什么 `inverse(model)` 很慢？

`inverse()` 是矩阵求逆运算，计算量较大。如果在顶点着色器中每帧对每个顶点都执行，会影响性能。

**优化方案**：在 C++ 端计算法线矩阵，作为 uniform 传入：

```cpp
glm::mat3 normalMatrix = glm::transpose(glm::inverse(glm::mat3(model)));
shader.setMat3("normalMatrix", normalMatrix);
```

> 注意：目前的 Shader 类没有 `setMat3` 方法，需要时添加。

### Q4：纹理叠加后颜色太暗或太亮？

纹理叠加的方式：

```glsl
FragColor = vec4(lighting * texColor.rgb, 1.0);
```

这是将光照结果与纹理颜色相乘。如果纹理本身较暗，最终结果会更暗。可以尝试：
- 提高 ambientStrength
- 使用更亮的纹理
- 在纹理采样后调整亮度

## 10. 下一步 / 预告

基础光照之后的下一个章节是 **材质（Materials）**。

在 Phong 模型中，三个分量的系数目前都是全局统一的。材质章节将：
- 为不同物体定义不同的材质属性（ambient、diffuse、specular、shininess）
- 支持多个光源
- 引入光照贴图（Lighting Maps）— 用纹理控制表面的不同区域有不同的光照响应

---

## 11. 关键知识点总结

### ✅ 需要掌握的

1. **Phong 光照模型三要素**：Ambient（环境光）+ Diffuse（漫反射）+ Specular（镜面反射）
2. **漫反射原理**：法线与光线方向的点积决定亮度 — `dot(normal, lightDir)`
3. **镜面反射原理**：视线与反射方向的点积决定高光 — `pow(dot(viewDir, reflectDir), shininess)`
4. **法线矩阵**：`transpose(inverse(model))` 的 3×3 部分，解决非均匀缩放的法线变换问题
5. **顶点数据扩展**：从 5 float/vertex 变为 8 float/vertex（新增法线）
6. **归一化**：法线在片段着色器中必须重新归一化 `normalize(Normal)`

### ✅ 已经掌握的技能链

```
窗口 → 三角形 → EBO/Shader封装 → 纹理 → 变换 → 坐标系统 → ImGui → 摄像机 → 颜色 → 🎯 基础光照
```
