## 1. 多光源场景概述

### 1.1 场景光源组成

本 Demo 包含 6 个光源：

```
场景
├── ① Directional Light（方向光/太阳）
│   方向：从右上斜照，全场景均匀
│   颜色：白光，强度 0.5（作为主光源之一）
│
├── ② Point Light × 4（点光源）
│   ├── 橙色：位置 (0.7, 0.2, 2.0) — 右前方近处
│   ├── 红色：位置 (2.3, -2.3, -4.0) — 右下远处
│   ├── 蓝色：位置 (-3.0, 2.0, -3.0) — 左上远处
│   └── 白色：位置 (0.0, -1.0, 0.0) — 底部补光
│
└── ③ SpotLight（聚光灯/手电筒）
    位置：跟随摄像机
    方向：指向场景原点
```

### 1.2 最终颜色公式

```
FragColor = 方向光 + Σ(点光源[i]) + 聚光灯
```

每种光源独立计算后累加。这个累加就是「多光源」的核心思想。

## 2. 着色器中的函数封装

### 2.1 为什么用函数？

三种光源类型的计算逻辑大部分相同（法线、衰减、漫反射、镜面反射），只是参数来源不同。用函数封装避免重复代码：

```cpp
vec3 calcDirLight(DirLight light, vec3 normal, vec3 viewDir, vec3 diffMap, vec3 specMap);
vec3 calcPointLight(PointLight light, vec3 normal, vec3 viewDir, vec3 diffMap, vec3 specMap);
vec3 calcSpotLight(SpotLight light, vec3 normal, vec3 viewDir, vec3 diffMap, vec3 specMap);
```

### 2.2 三种结构体

```cpp
struct DirLight {
    vec3 direction;
    vec3 ambient;
    vec3 diffuse;
    vec3 specular;
};

struct PointLight {
    vec3 position;
    vec3 ambient;
    vec3 diffuse;
    vec3 specular;
    float constant;
    float linear;
    float quadratic;
};

struct SpotLight {
    vec3 position;
    vec3 direction;
    float cutOff;
    float outerCutOff;
    vec3 ambient;
    vec3 diffuse;
    vec3 specular;
    float constant;
    float linear;
    float quadratic;
};
```

### 2.3 主函数结构

```cpp
void main()
{
    // 公共输入
    vec3 diffMap = vec3(texture(material.diffuse, TexCoord));
    vec3 specMap = vec3(texture(material.specular, TexCoord));
    vec3 norm    = normalize(Normal);
    vec3 viewDir = normalize(viewPos - FragPos);

    // 累加各光源贡献
    vec3 result = calcDirLight(dirLight, norm, viewDir, diffMap, specMap);

    for (int i = 0; i < NR_POINT_LIGHTS; i++)
        result += calcPointLight(pointLights[i], norm, viewDir, diffMap, specMap);

    result += calcSpotLight(spotLight, norm, viewDir, diffMap, specMap);

    FragColor = vec4(result, 1.0);
}
```

## 3. 方向光 + 4 个点光源 + 聚光灯

### 3.1 方向光设置

```cpp
// C++ 端
dirLight.direction = glm::vec3(-0.3f, -0.5f, -0.5f);  // 从右上斜照
dirLight.ambient   = glm::vec3(0.08f);                   // 很暗
dirLight.diffuse   = glm::vec3(0.5f);                    // 中等
dirLight.specular  = glm::vec3(0.6f);                    // 中等
```

- 环境光很弱（0.08），避免画面发灰
- 漫反射中等（0.5），为主光源之一但不是唯一
- 各点光源贡献额外的颜色

### 3.2 点光源数组

4 个点光源用 `PointLight pl[4]` 数组存储，着色器用循环遍历：

```cpp
#define NR_POINT_LIGHTS 4
uniform PointLight pointLights[NR_POINT_LIGHTS];
```

C++ 端设置 uniform（用数组下标区分不同光源）：

```cpp
for (int i = 0; i < 4; i++) {
    std::string idx = "pointLights[" + std::to_string(i) + "]";
    shader.setVec3(idx + ".position", pl[i].position.x, pl[i].position.y, pl[i].position.z);
    shader.setVec3(idx + ".ambient", amb.x, amb.y, amb.z);
    // ...
}
```

### 3.3 各光源颜色

| 索引 | 颜色 | 位置 | 作用 |
|:----:|------|------|------|
| 0 | 橙 | 右前方 | 暖色主补光 |
| 1 | 红 | 右下远处 | 冷色点缀 |
| 2 | 蓝 | 左上远处 | 冷暖对比 |
| 3 | 白 | 底部 | 底部补光 |

### 3.4 聚光灯跟随摄像机

```cpp
// 每帧更新
vec3 spotPos = camPos;
vec3 spotDir = normalize(vec3(0.0f) - camPos);  // 指向原点

shader.setVec3("spotLight.position", spotPos.x, spotPos.y, spotPos.z);
shader.setVec3("spotLight.direction", spotDir.x, spotDir.y, spotDir.z);
```

聚光灯的位置和方向每帧随摄像机更新，实现「手电筒」效果。

## 4. 点光源数组

### 4.1 着色器中的数组

GLSL 支持结构体数组：

```cpp
#define NR_POINT_LIGHTS 4
uniform PointLight pointLights[NR_POINT_LIGHTS];
```

遍历数组累加：

```cpp
vec3 result = vec3(0.0);
for (int i = 0; i < NR_POINT_LIGHTS; i++)
    result += calcPointLight(pointLights[i], norm, viewDir, diffMap, specMap);
```

### 4.2 C++ 端设置 Uniform 数组

动态构造 uniform 名称：

```cpp
for (int i = 0; i < NR_POINT_LIGHTS; i++) {
    string prefix = "pointLights[" + to_string(i) + "]";
    shader.setVec3(prefix + ".position", pos.x, pos.y, pos.z);
    shader.setVec3(prefix + ".ambient", amb.x, amb.y, amb.z);
    // ...
}
```

这是 GLSL 中处理 uniform 数组的标准方式——每个数组元素是一个独立的 uniform 变量。

### 4.3 启停控制

每个点光源可以独立开关：

```cpp
if (enabled) {
    // 设置正常值
} else {
    // 将颜色设为 0（等效关闭）
    shader.setVec3(idx + ".ambient", 0, 0, 0);
    shader.setVec3(idx + ".diffuse", 0, 0, 0);
    shader.setVec3(idx + ".specular", 0, 0, 0);
}
```

## 5. 聚光灯跟随摄像机

### 5.1 实现方式

聚光灯（手电筒）的关键特性：**位置和方向随摄像机变化**。

```cpp
// 位置 = 摄像机位置
spotLight.position = camPos;

// 方向 = 从摄像机指向场景中心
spotLight.direction = normalize(origin - camPos);
```

### 5.2 效果

- 摄像机移动到某处，聚光灯就跟到某处
- 只有摄像机正对的方向被照亮
- 营造「探照灯/手电筒」的第一人称效果

### 5.3 F 键开关

按 **F** 键可以快速开关聚光灯，对比有/无手电筒的效果差异。

| 控制项 | 作用 |
|--------|------|

| **Point Light [0-3]** | 各点光源独立开关 + 位置/颜色 |

### 推荐操作

1. **关闭方向光**，观察纯点光源的效果（五彩斑斓的光照）
2. **逐个关闭点光源**，观察场景颜色的变化
3. **按 F 开关聚光灯**，感受手电筒效果
4. **移动摄像机**，观察聚光灯跟随移动

## 7. 常见问题

### Q1：多光源性能如何？会不会很慢？

6 个光源 × 10 个立方体 × 每个立方体 36 个三角形 × 经过光栅化的片段数。对现代 GPU 来说，这个负载很小。

但如果点光源数量增加到几十个，就需要考虑优化：
- 只计算**距离近**的光源（光源裁剪）
- 使用**延迟渲染**（Deferred Shading）减少重复计算

### Q2：为什么每个点光源的颜色要拆分成 ambient/diffuse/specular？

```cpp
ambient  = color * 0.2f;   // 环境光：很暗
diffuse  = color * 0.8f;   // 漫反射：主色
specular = color * 1.0f;   // 镜面反射：纯色
```

这是常见的简化：环境光用暗色的主色，镜面反射用亮色的主色。实际可以自由调节。

### Q3：多光源的累加会不会过曝？

```
最终结果 = 方向光 + 点光源[0] + 点光源[1] + ... + 聚光灯
```

如果所有光源都很亮，结果确实可能超过 1.0（过曝）。这里的处理方式是：
- 各光源的 diffuse/specular 系数较小（0.3~0.5）
- 环境光系数很小（0.05~0.2）
- 让多个光源叠加后总量在合理范围

更高级的做法是用 HDR（高动态范围）+ Tone Mapping，这会在后续章节介绍。

### Q4：着色器函数比内联代码慢吗？

不会。着色器函数调用在 GPU 上编译为内联指令，**没有函数调用开销**。

## 9. 关键知识点总结

### ✅ 需要掌握的

1. **多光源累加**：最终颜色 = 各光源贡献之和
2. **着色器函数**：每种光源类型封装为独立函数，减少重复
3. **Uniform 数组**：结构体数组 + `string` 构造 uniform 名称
4. **手电筒跟随**：聚光灯位置/方向每帧随摄像机更新
5. **光源独立开关**：通过将颜色设为 0 实现关闭效果
6. **多光源平衡**：各光源的强度系数要合理，避免过曝

```
窗口 → 三角形 → EBO/Shader封装 → 纹理 → 变换 → 坐标系统 → ImGui
→ 摄像机 → 颜色 → 基础光照 → 材质 → 光照贴图 → 投光物 → 🎯 多光源
```
