## 1. 为什么需要材质？

### 1.1 基础光照的局限

在基础光照章节中，Phong 模型使用**全局系数**：

```
result = (ambient + diffuse + specular) × objectColor
```

所有物体共享同一个 `ambientStrength`、`specularStrength`、`shininess`。这意味着：
- 金属、塑料、橡胶在光照下表现完全一样（只是颜色不同）
- 无法模拟金、银、铜各自独特的光泽

### 1.2 材质的核心思想

不同物体有不同的**表面属性**，这些属性决定了它们如何反射光线：

```
金属：     环境光有色 + 漫反射有色 +  强镜面反射（带金属色）
塑料：     无环境光   + 鲜艳漫反射 +  白色高光
橡胶：     无环境光   + 暗漫反射   +  非常弱的高光
翡翠：     深绿环境光 + 亮绿漫反射 +  绿色镜面反射（高反光）
```

## 2. Material 结构体

### 2.1 定义

```cpp
struct Material {
    vec3 ambient;       // 环境光反射颜色
    vec3 diffuse;       // 漫反射反射颜色（物体「本身」的颜色）
    vec3 specular;      // 镜面反射反射颜色（高光颜色）
    float shininess;    // 反光度
};
```

### 2.2 各分量含义

| 分量 | 控制什么 | 典型值 |
|------|---------|--------|
| `ambient` | 物体在暗处的颜色 | 金属有颜色，塑料为黑色 (0,0,0) |
| `diffuse` | 物体在光照下的主色 | 物体的「本征颜色」 |
| `specular` | 高光的颜色 | 金属有颜色，塑料/橡胶为白色 |
| `shininess` | 高光大小 | 光滑表面 100+，粗糙表面 < 20 |

### 2.3 关键理解

> **Material 的颜色决定了物体反射什么颜色的光。**

- 红色塑料的 `material.diffuse = (0.5, 0.0, 0.0)` — 只反射红色
- 金的 `material.specular = (0.628, 0.556, 0.366)` — 高光是金色的
- 红塑料的 `material.specular = (0.7, 0.6, 0.6)` — 高光是偏白的（不带有色金属感）

## 3. Light 结构体

### 3.1 定义

```cpp
struct Light {
    vec3 position;      // 光源位置

    vec3 ambient;       // 光源发出的环境光
    vec3 diffuse;       // 光源发出的漫反射光（光源的主色）
    vec3 specular;      // 光源发出的镜面反射光
};
```

### 3.2 各分量的独立控制

灯光的不同分量可以有不同的颜色：

```
典型白色光源：
  light.ambient  = (0.2, 0.2, 0.2)   — 很暗（环境光只是避免全黑）
  light.diffuse  = (0.8, 0.8, 0.8)   — 亮白（光源的主色）
  light.specular = (1.0, 1.0, 1.0)   — 纯白（高光通常是白的）

暖色光源（日落）：
  light.ambient  = (0.1, 0.05, 0.02)
  light.diffuse  = (0.8, 0.4, 0.15)
  light.specular = (0.9, 0.5, 0.2)
```

## 4. 光照计算的变化

### 4.1 公式对比

**基础光照：**

```cpp
vec3 ambient  = ambientStrength * lightColor;
vec3 diffuse  = diff * lightColor;
vec3 specular = specularStrength * spec * lightColor;
vec3 result = (ambient + diffuse + specular) * objectColor;
```

**材质：**

```cpp
vec3 ambient  = light.ambient  * material.ambient;
vec3 diffuse  = light.diffuse  * (diff * material.diffuse);
vec3 specular = light.specular * (spec * material.specular);
vec3 result = ambient + diffuse + specular;
```

### 4.2 关键变化

| 方面 | 基础光照 | 材质 |
|------|---------|------|
| 环境光 | `strength × lightColor` | `light.ambient × material.ambient` |
| 漫反射 | `diff × lightColor` | `light.diffuse × material.diffuse × diff` |
| 镜面反射 | `strength × spec × lightColor` | `light.specular × material.specular × spec` |
| 颜色控制 | 全局 `objectColor` | 三个分量各自独立颜色 |
| 最后乘法 | `(a+d+s) × objectColor` | 无需额外乘法（颜色已在分量中） |

## 5. 材质预设

### 5.1 Demo 中内置的 10 种材质

| 材质 | ambient | diffuse | specular | shininess | 特点 |
|------|---------|---------|----------|-----------|------|
| **Gold (金)** | 暗黄 | 亮金 | 金色高光 | 51.2 | 金属光泽，温暖色调 |
| **Silver (银)** | 深灰 | 银白 | 银白高光 | 51.2 | 冷色金属感 |
| **Bronze (青铜)** | 暗棕 | 暖棕 | 暖棕高光 | 25.6 | 复古金属 |
| **Copper (铜)** | 深红棕 | 亮橙棕 | 红棕高光 | 12.8 | 高光范围大 |
| **Red Plastic (红塑料)** | 黑 | 鲜红 | 白色高光 | 32.0 | 鲜艳，塑料感 |
| **Cyan Rubber (青橡胶)** | 黑 | 暗青 | 很弱亮青 | 12.8 | 哑光橡胶 |
| **Emerald (翡翠)** | 深绿 | 亮绿 | 淡绿高光 | 76.8 | 宝石感，高反光 |
| **Obsidian (黑曜石)** | 深紫黑 | 暗紫 | 亮紫高光 | 38.4 | 暗色宝石 |
| **Pearl (珍珠)** | 暖粉 | 浅粉 | 柔和白色 | 11.3 | 柔和光泽 |
| **Ruby (红宝石)** | 深红 | 亮红 | 粉色高光 | 76.8 | 鲜艳宝石 |

### 5.2 材质差异的可视化

```
金属 vs 塑料 的核心区别在于 specular 的颜色：

  金属：specular ≈ diffuse 的颜色（有色高光）
        → 高光看起来是「金属本身在发光」
  
  塑料：specular = white（白色高光）
        → 高光是「灯光的颜色照在塑料上」
```

## 6. 着色器实现

### 6.1 顶点着色器

复用 `basic_lighting.vert`（与基础光照章节相同）。

### 6.2 片段着色器 `materials.frag`

```cpp
#version 330 core
out vec4 FragColor;

in vec3 FragPos;
in vec3 Normal;
in vec2 TexCoord;

struct Material {
    vec3 ambient;
    vec3 diffuse;
    vec3 specular;
    float shininess;
};

struct Light {
    vec3 position;
    vec3 ambient;
    vec3 diffuse;
    vec3 specular;
};

uniform Material material;
uniform Light light;
uniform vec3 viewPos;

void main()
{
    // Ambient
    vec3 ambient = light.ambient * material.ambient;

    // Diffuse
    vec3 norm = normalize(Normal);
    vec3 lightDir = normalize(light.position - FragPos);
    float diff = max(dot(norm, lightDir), 0.0);
    vec3 diffuse = light.diffuse * (diff * material.diffuse);

    // Specular
    vec3 viewDir = normalize(viewPos - FragPos);
    vec3 reflectDir = reflect(-lightDir, norm);
    float spec = pow(max(dot(viewDir, reflectDir), 0.0), material.shininess);
    vec3 specular = light.specular * (spec * material.specular);

    // Result
    vec3 result = ambient + diffuse + specular;
    FragColor = vec4(result, 1.0);
}
```

## 7. C++ 设置 Uniform

### 7.1 结构体成员的 Uniform 访问

GLSL 中结构体的成员通过点号访问，C++ 端设置 uniform 时也用点号：

```cpp
// 设置材质
lightingShader.setVec3("material.ambient",   matAmbient.r,   matAmbient.g,   matAmbient.b);
lightingShader.setVec3("material.diffuse",   matDiffuse.r,   matDiffuse.g,   matDiffuse.b);
lightingShader.setVec3("material.specular",  matSpecular.r,  matSpecular.g,  matSpecular.b);
lightingShader.setFloat("material.shininess", matShininess);

// 设置光源
lightingShader.setVec3("light.position",  lightPos.x, lightPos.y, lightPos.z);
lightingShader.setVec3("light.ambient",   lightAmbient.r,   lightAmbient.g,   lightAmbient.b);
lightingShader.setVec3("light.diffuse",   lightDiffuse.r,   lightDiffuse.g,   lightDiffuse.b);
lightingShader.setVec3("light.specular",  lightSpecular.r,  lightSpecular.g,  lightSpecular.b);

// 设置摄像机位置
lightingShader.setVec3("viewPos", camPos.x, camPos.y, camPos.z);
```

### 7.2 材质预设切换

在 ImGui 中选择预设后，将预设值复制到当前材质变量：

```cpp
int prevMaterial = currentMaterial;
ImGui::Combo("Preset", &currentMaterial, comboItems);
if (currentMaterial != prevMaterial)
{
    matAmbient   = MATERIALS[currentMaterial].ambient;
    matDiffuse   = MATERIALS[currentMaterial].diffuse;
    matSpecular  = MATERIALS[currentMaterial].specular;
    matShininess = MATERIALS[currentMaterial].shininess;
    // 同步到 ImGui 颜色数组
}
```

## 9. 常见问题

### Q1：切换材质预设后修改颜色，预设名不变？

这是一个预期行为。Demo 没有"Custom"选项——选择预设后你可以自由修改属性，预设名保留但不影响实际的材质属性值。你可以认为选取预设只是快速填充了一组值。

### Q2：为什么有些材质没有环境光（ambient = 黑色）？

塑料和橡胶类材质的环境光反射通常为黑色（0,0,0），这意味着它们不反射环境光。在实际生活中，塑料确实看起来更"暗"，而金属即使在没有强光照射时也呈现一定的颜色。

这是一种简化模拟，并非物理准确，但在视觉上效果足够好。

### Q3：材质的颜色和纹理有什么关系？

材质属性（ambient/diffuse/specular）决定了物体**整体**的光照响应。

纹理（下章节的「光照贴图」）可以让物体**不同区域**有不同的光照响应——
比如一个木箱，木纹部分和金属包角部分有不同的材质属性。

### Q4：`light.ambient` 和 `material.ambient` 各起什么作用？

```
light.ambient   — 场景中有多少环境光（全局）
material.ambient — 物体能反射多少环境光（局部）

final ambient = light.ambient × material.ambient
```

两者相乘。通常：
- `light.ambient` 是全局统一的微弱光
- `material.ambient` 因材质而异（金属有色，塑料黑色）

## 10. 下一步 / 预告

材质的下一章是**光照贴图（Lighting Maps）**：

```
材质章节：物体只有一个 Material 属性，整体一致
光照贴图：用纹理控制物体不同区域的 Material 属性
          → ambient map（环境光贴图）
          → diffuse map（漫反射贴图，即普通纹理）
          → specular map（镜面反射贴图）
```

光照贴图让材质差异更精细：一个木箱的木头部分和铁箍部分有不同的 specular 响应。

## 11. 关键知识点总结

### ✅ 需要掌握的

1. **Material 结构体**：`ambient` + `diffuse` + `specular` + `shininess` — 定义物体如何反射光线
2. **Light 结构体**：`position` + `ambient` + `diffuse` + `specular` — 定义光源的各分量颜色
3. **材质 vs 基础光照**：从全局系数到独立颜色控制，三个分量的颜色各自独立
4. **金属 vs 塑料**：金属的 specular 有色（≈diffuse），塑料的 specular 为白色
5. **结构体 uniform**：用点号访问成员，如 `material.ambient`、`light.diffuse`
6. **材质预设**：10 种常见的材质参数，理解不同材质的参数配置思路
