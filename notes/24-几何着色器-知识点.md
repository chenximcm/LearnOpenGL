## 1. 概述

**几何着色器（Geometry Shader）** 是渲染管线中位于顶点着色器和片段着色器之间的可选阶段。它接收一个**完整的图元**（点、线、三角形）作为输入，可以：

- ✂️ **修改图元** — 改变顶点位置（如爆破效果）
- ➕ **生成新图元** — 从点生成房子、粒子扩展为四边形
- ➖ **删除图元** — 丢弃不需要的三角形
- 🔀 **改变图元类型** — 三角形 → 线段（法线可视化）

### 1.1 管线位置

```
顶点数据 → [顶点着色器] → [几何着色器] → [片段着色器] → 屏幕
              ↓                ↓                ↓
         逐顶点处理        逐图元处理        逐片段处理
                       ★ 本章重点 ★
```

## 2. 几何着色器的位置与工作原理

### 2.1 输入/输出图元类型

```glsl
// 输入图元类型（来自顶点着色器装配后的结果）
layout (points) in;              // 点
layout (lines) in;               // 线段（2 个顶点）
layout (lines_adjacency) in;     // 带邻接的线段
layout (triangles) in;           // 三角形（3 个顶点）
layout (triangles_adjacency) in; // 带邻接的三角形

// 输出图元类型 + 最大顶点数
layout (points, max_vertices = 1) out;
layout (line_strip, max_vertices = 2) out;
layout (triangle_strip, max_vertices = 3) out;
```

### 2.2 核心函数

| 函数 | 作用 |
|------|------|
| `EmitVertex()` | 发射当前 `gl_Position` 和 `out` 变量作为一个新顶点 |
| `EndPrimitive()` | 结束当前输出图元（下一个 `EmitVertex()` 开启新图元） |
| `gl_in[i].gl_Position` | 内建数组，存储输入图元的顶点位置（经过 VS 变换） |

### 2.3 几何着色器的创建（C++ 端）

```cpp
// 创建几何着色器对象（注意类型是 GL_GEOMETRY_SHADER）
GLuint geometryShader = glCreateShader(GL_GEOMETRY_SHADER);
glShaderSource(geometryShader, 1, &geometryShaderCode, NULL);
glCompileShader(geometryShader);

// 附着到程序
glAttachShader(program, vertexShader);
glAttachShader(program, geometryShader);
glAttachShader(program, fragmentShader);
glLinkProgram(program);
```

## 3. 基础示例：直通几何着色器

最简单的几何着色器 —— 不做任何处理，直接传递顶点：

```glsl
#version 330 core
layout (points) in;                    // 输入：点
layout (points, max_vertices = 1) out; // 输出：点，最多 1 个顶点

void main()
{
    gl_Position = gl_in[0].gl_Position;  // 直传位置
    EmitVertex();                         // 发射顶点
    EndPrimitive();                       // 结束图元
}
```

> **关键理解**：`gl_in[]` 是一个数组，大小等于输入图元的顶点数。对于 `points`，数组大小为 1；对于 `triangles`，数组大小为 3。

## 4. 法线可视化（Normal Visualization）

### 4.1 原理

将三角形的每个顶点沿其法线方向画一条短线段，直观展示法线分布。

```
三角形顶点 A ──→ 沿法线画线
三角形顶点 B ──→ 沿法线画线  
三角形顶点 C ──→ 沿法线画线
```

### 4.2 顶点着色器

将位置和法线变换到**观察空间**：

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;
layout (location = 1) in vec3 aNormal;

out VS_OUT {
    vec3 normal;
} vs_out;

uniform mat4 view;
uniform mat4 model;

void main()
{
    gl_Position = view * model * vec4(aPos, 1.0);   // 观察空间位置
    mat3 normalMatrix = mat3(transpose(inverse(view * model)));
    vs_out.normal = normalize(vec3(vec4(normalMatrix * aNormal, 0.0)));
}
```

### 4.3 几何着色器（核心）

```glsl
#version 330 core
layout (triangles) in;                    // 输入：三角形
layout (line_strip, max_vertices = 6) out; // 输出：线段（3条线 × 2个顶点）

in VS_OUT {
    vec3 normal;
} gs_in[];

uniform mat4 projection;
const float MAGNITUDE = 0.2;

void GenerateLine(int index)
{
    gl_Position = projection * gl_in[index].gl_Position;
    EmitVertex();   // 线段起点
    gl_Position = projection * (gl_in[index].gl_Position +
                                vec4(gs_in[index].normal, 0.0) * MAGNITUDE);
    EmitVertex();   // 线段终点
    EndPrimitive(); // ★ 结束当前线段（下一条是新线段）
}

void main()
{
    GenerateLine(0);
    GenerateLine(1);
    GenerateLine(2);
}
```

### 4.4 片段着色器

```glsl
#version 330 core
out vec4 FragColor;
void main() {
    FragColor = vec4(1.0, 1.0, 0.0, 1.0);  // 黄色法线
}
```

## 5. 爆破物体（Exploding Objects）

### 5.1 原理

在几何着色器中计算三角形面的法线，然后将每个顶点沿面法线方向位移。

### 5.2 顶点着色器

传递世界空间位置：

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;
layout (location = 2) in vec2 aTexCoords;

out VS_OUT { vec2 texCoords; } vs_out;
uniform mat4 model;

void main()
{
    gl_Position = model * vec4(aPos, 1.0);   // 世界空间位置
    vs_out.texCoords = aTexCoords;
}
```

### 5.3 几何着色器（核心）

```glsl
#version 330 core
layout (triangles) in;
layout (triangle_strip, max_vertices = 3) out;

in VS_OUT { vec2 texCoords; } gs_in[];
out vec2 TexCoords;

uniform mat4 view, projection;
uniform float time;

vec3 GetNormal() {
    vec3 a = vec3(gl_in[0].gl_Position) - vec3(gl_in[1].gl_Position);
    vec3 b = vec3(gl_in[2].gl_Position) - vec3(gl_in[1].gl_Position);
    return normalize(cross(a, b));
}

vec4 explode(vec4 position, vec3 normal) {
    float magnitude = 0.8;
    vec3 direction = normal * ((sin(time) + 1.0) / 2.0) * magnitude;
    return position + vec4(direction, 0.0);
}

void main() {
    vec3 normal = GetNormal();  // ★ 计算面法线

    gl_Position = projection * view * explode(gl_in[0].gl_Position, normal);
    TexCoords = gs_in[0].texCoords;  EmitVertex();

    gl_Position = projection * view * explode(gl_in[1].gl_Position, normal);
    TexCoords = gs_in[1].texCoords;  EmitVertex();

    gl_Position = projection * view * explode(gl_in[2].gl_Position, normal);
    TexCoords = gs_in[2].texCoords;  EmitVertex();

    EndPrimitive();
}
```

> **关键**：`GetNormal()` 在几何着色器中计算法线，因为这里可以访问三角形的全部 3 个顶点。

## 6. 造房子（Building Houses）

### 6.1 原理

输入 4 个**点**（位置 + 颜色），几何着色器为每个点生成 5 个顶点（三角形带），组成房子形状。

```
    5(屋顶白)
    /\
   /  \
 3/____\4
 |      |
 |______|
 1      2

三角形: (1,2,3) (2,3,4) (3,4,5)
```

### 6.2 顶点着色器

```glsl
#version 330 core
layout (location = 0) in vec2 aPos;
layout (location = 1) in vec3 aColor;

out VS_OUT { vec3 color; } vs_out;

void main() {
    gl_Position = vec4(aPos.x, aPos.y, 0.0, 1.0);
    vs_out.color = aColor;
}
```

### 6.3 几何着色器（核心）

```glsl
#version 330 core
layout (points) in;                          // ★ 输入是点！
layout (triangle_strip, max_vertices = 5) out; // ★ 输出是三角形带！

in VS_OUT { vec3 color; } gs_in[];
out vec3 fColor;

void build_house(vec4 position) {
    fColor = gs_in[0].color;
    gl_Position = position + vec4(-0.2, -0.2, 0.0, 0.0); EmitVertex();  // 1
    gl_Position = position + vec4( 0.2, -0.2, 0.0, 0.0); EmitVertex();  // 2
    gl_Position = position + vec4(-0.2,  0.2, 0.0, 0.0); EmitVertex();  // 3
    gl_Position = position + vec4( 0.2,  0.2, 0.0, 0.0); EmitVertex();  // 4
    gl_Position = position + vec4( 0.0,  0.4, 0.0, 0.0);
    fColor = vec3(1.0);  // 白色屋顶
    EmitVertex();                                                       // 5
    EndPrimitive();
}

void main() {
    build_house(gl_in[0].gl_Position);
}
```

### 6.4 C++ 绘制调用

```cpp
// ★ 顶点数据用 GL_POINTS 绘制，因为几何着色器输入是 points！
glDrawArrays(GL_POINTS, 0, 4);
```

**重要**：绘制调用的图元类型必须与几何着色器的**输入**图元类型匹配！

## 7. Shader 类扩展 — 支持几何着色器

在 `shader.h` 中新增三参数构造函数：

```cpp
Shader(const char* vertexSource, const char* geometrySource,
       const char* fragmentSource, bool fromFile = false);

// 用法示例：
Shader explodeShader(
    "shaders/geometry_shader/geom_explode.vert",
    "shaders/geometry_shader/geom_explode.geom",
    "shaders/geometry_shader/geom_explode.frag",
    true);
```

内部编译逻辑新增 `GL_GEOMETRY_SHADER` 分支：

```cpp
unsigned int geometryShader = glCreateShader(GL_GEOMETRY_SHADER);
glShaderSource(geometryShader, 1, &geometrySource, NULL);
glCompileShader(geometryShader);
checkCompileErrors(geometryShader, "GEOMETRY");
// ...
glAttachShader(ID, geometryShader);
```

## 9. 关键知识点总结

### 9.1 几何着色器核心概念

| 概念 | 说明 |
|------|------|
| **位置** | 渲染管线中 VS → GS → FS |
| **输入** | 完整图元（points / lines / triangles） |
| **输出** | 可改变图元类型和顶点数量 |
| **gl_in[]** | 输入顶点数组（含 gl_Position 和用户 in 变量） |
| **EmitVertex()** | 发射当前状态作为一个顶点 |
| **EndPrimitive()** | 结束当前输出图元 |

### 9.2 三种经典应用

| 应用 | 输入 | 输出 | 关键技术 |
|------|------|------|---------|
| 法线可视化 | triangles | line_strip | 每个顶点发射线段 |
| 爆破物体 | triangles | triangle_strip | 面法线计算 + 顶点位移 |
| 造房子 | points | triangle_strip | 从 1 个点生成 5 个顶点 |

### 9.3 重要注意事项

1. **绘制调用与输入匹配**：`glDrawArrays(GL_POINTS, ...)` 对应 `layout (points) in`
2. **max_vertices 限制**：硬件对几何着色器的输出顶点数有上限
3. **性能考虑**：几何着色器可能成为瓶颈，大量顶点生成需谨慎
4. **坐标空间**：法线可视化在观察空间计算，爆破在局部空间计算
