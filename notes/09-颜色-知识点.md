## 1. 颜色的本质

### 1.1 人眼如何感知颜色

人眼看到的颜色 = **物体反射了什么光**。

- 白色物体：反射了所有颜色的光（红 + 绿 + 蓝全反射）
- 红色物体：只反射**红色**光，吸收绿光和蓝光
- 蓝色物体：只反射**蓝色**光，吸收红光和绿光

> 💡 物体呈现的颜色取决于它**反射**了什么波长的光，而不是它「本身」的颜色。

### 1.2 计算机图形学中的颜色模型

我们用 RGB 三元组表示颜色：

| 颜色 | RGB 值 |
|------|--------|
| 红 | (1.0, 0.0, 0.0) |
| 绿 | (0.0, 1.0, 0.0) |
| 蓝 | (0.0, 0.0, 1.0) |
| 白 | (1.0, 1.0, 1.0) |
| 黄 | (1.0, 1.0, 0.0) |
| 珊瑚色 | (1.0, 0.5, 0.31) |

## 2. 光照颜色 × 物体颜色

### 2.1 核心公式

```
Perceived Color = Light Color × Object Color
```

这是**逐分量乘法**（component-wise multiplication）：

```
result.r = light.r * object.r
result.g = light.g * object.g
result.b = light.b * object.b
```

### 2.2 例子

| 光源颜色 | × | 物体颜色 | = | 感知颜色 |
|----------|---|---------|---|---------|
| 白 (1.0, 1.0, 1.0) | × | 珊瑚 (1.0, 0.5, 0.31) | = | 珊瑚 (1.0, 0.5, 0.31) |
| 绿 (0.0, 1.0, 0.0) | × | 珊瑚 (1.0, 0.5, 0.31) | = | 黑 (0.0, 0.0, 0.0) |
| 红 (1.0, 0.0, 0.0) | × | 白 (1.0, 1.0, 1.0) | = | 红 (1.0, 0.0, 0.0) |

**直观理解**：

- 物体颜色定义了这个物体能「反射」什么颜色的光
- 光源颜色定义了这个光源「发出」什么颜色的光
- 两者相乘：只有光源发出且物体能反射的颜色才能被人眼看到

### 2.3 物理意义

> 光源颜色 × 物体颜色 = 反射光的颜色

```
红色物体 + 绿色光源 → 黑色
```

红色物体只能反射红色，但绿色光源中不含红色分量 — 所以结果全黑，物体看起来是黑的。

## 3. 代码实战

### 3.1 着色器代码

**片段着色器** `shaders/lighting/colors.frag`：

```glsl
#version 330 core
out vec4 FragColor;

uniform vec3 objectColor;
uniform vec3 lightColor;

void main()
{
    vec3 result = lightColor * objectColor;
    FragColor = vec4(result, 1.0);
}
```

### 3.2 C++ 端设置 Uniform

```cpp
lightingShader.use();
lightingShader.setVec3("lightColor",  lightColor.x,  lightColor.y,  lightColor.z);
lightingShader.setVec3("objectColor", objectColor.x, objectColor.y, objectColor.z);
```

### 3.3 Shader 封装回顾

利用之前封装的 `Shader` 类的 `setVec3()` 方法传递颜色：

```cpp
// shader.h
void setVec3(const std::string& name, float x, float y, float z) const
{
    glUniform3f(glGetUniformLocation(ID, name.c_str()), x, y, z);
}
```

### 3.4 顶点数据

与坐标系统 / 摄像机章节相同：

```
[ 位置 (3 float) | 纹理坐标 (2 float) ]
```

> 💡 颜色章节不需要法线（Normal），法线会在下个章节「基础光照」中引入。

## 4. 光源表示（Light Source Representation）

### 4.1 为什么要光源表示？

为了直观看到「光源在哪里」以及「光源是什么颜色」，我们在场景中添加一个**代表光源的小立方体**。

### 4.2 两套 VAO / 两套 Shader

| 物体 | VAO | 着色器 | 说明 |
|------|-----|--------|------|
| 主立方体（被光照） | `cubeVAO` | `coordinate_system.vert` + `colors.frag` | 应用颜色乘法 |
| 光源标记 | `lightVAO` | `light_cube.vert` + `light_cube.frag` | 纯色输出 |

### 4.3 VAO 共享 VBO

两个 VAO 共享同一份 VBO 数据：

```cpp
// cubeVAO：启用位置 + 纹理坐标两个属性
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 5 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
glVertexAttribPointer(1, 2, GL_FLOAT, GL_FALSE, 5 * sizeof(float), (void*)(3 * sizeof(float)));
glEnableVertexAttribArray(1);

// lightVAO：只启用位置属性
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 5 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
```

> **关键理解**：不同 VAO 可以共享同一个 VBO，通过不同的属性配置来读取不同的数据。

### 4.4 光源着色器

**顶点着色器**（只需要位置 + MVP）：

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;

uniform mat4 model;
uniform mat4 view;
uniform mat4 projection;

void main()
{
    gl_Position = projection * view * model * vec4(aPos, 1.0);
}
```

**片段着色器**（直接输出光源颜色）：

```glsl
#version 330 core
out vec4 FragColor;

uniform vec3 lightColor;

void main()
{
    FragColor = vec4(lightColor, 1.0);
}
```

### 4.5 模型矩阵缩放

光源标记的大小缩小到原来的 20%：

```cpp
model = glm::translate(model, lightPos);
model = glm::scale(model, glm::vec3(0.2f));
```

## 6. 常见问题

### Q1：为什么用绿色光照红色物体结果是黑色？

```
Light (0, 1, 0) × Object (1, 0, 0) = (0, 0, 0)
```

绿色光源不含红色分量（G=1, R=0），红色物体只能反射红色分量（R=1）。两者相乘，没有任何分量 > 0，所以是黑色。

### Q2：为什么光源立方体不受颜色计算影响？

因为光源立方体使用**独立的着色器**（`light_cube.frag`），它直接输出 `lightColor` 作为片段颜色，不经过乘法运算。它只是视觉上的位置标记，模拟「发光」的效果。

### Q3：纹理和颜色计算有什么关系？

两者是独立的：
- 纹理决定物体表面的**图案细节**
- 颜色计算决定物体表面的**光照颜色**

在 Demo 中，可以通过 `Use Texture` 开关观察效果。当纹理开启时，主立方体显示纹理图案并叠加颜色效果。

## 7. 下一步 / 预告

颜色章节只是一个概念引入，**真正的光照效果**将在下个章节展开。

### 基础光照（Basic Lighting）预告

| 光照分量 | 作用 | 直观理解 |
|----------|------|---------|
| **Ambient**（环境光） | 最低亮度保证背面不黑 | 房间中无处不在的微弱光 |
| **Diffuse**（漫反射） | 法线与光线夹角决定亮度 | 手电筒斜照 vs 直照 |
| **Specular**（镜面反射） | 视角与反射光线夹角决定高光 | 金属表面的反光亮点 |

- 在片段着色器中分别计算 Ambient / Diffuse / Specular

## 8. 关键知识点总结

### ✅ 需要掌握的

1. **颜色乘法**：`Perceived = Light × Object`（逐分量乘法）
2. **物理本质**：物体反射了什么颜色的光 = 人眼看到了什么颜色
3. **VAO 共享 VBO**：两个 VAO 可以共享同一份顶点数据，通过不同的属性配置控制读取方式
4. **两套着色器**：主物体和光源标记用不同的着色器，各自负责不同的渲染逻辑
