## 1. 概述

**混合（Blending）** 是 OpenGL 高级部分的第三章。前面的深度测试和模板测试都在决定"片段是否通过"，而混合决定了**片段如何与已有颜色合并**。

### 1.1 透明度问题的本质

在 OpenGL 中，纹理颜色可以包含 Alpha 通道（第 4 个分量），它表示透明度：

| Alpha 值 | 含义 |
|---------|------|
| 1.0 | 完全不透明 |
| 0.5 | 半透明（50%） |
| 0.0 | 完全透明 |

但仅靠 Alpha 通道还不够 — 渲染管线默认**不会**将 Alpha 值当作透明度处理。我们需要手动告诉 OpenGL 如何处理。

### 1.2 两种处理方式

| 方式 | 原理 | 适用场景 |
|------|------|---------|
| **Alpha 丢弃** (discard) | 在片段着色器中丢弃透明像素 | 只有"全透明/全不透明"的纹理（草叶、栅栏） |
| **混合** (Blending) | 将片段颜色与已有颜色按比例混合 | 半透明物体（玻璃、水面、粒子） |

### 1.3 渲染管线中的位置

```
片段着色器 → 模板测试 → 深度测试 → 混合 → 帧缓冲
                                          ↑
                                  glEnable(GL_BLEND)
```

混合是 **管线的最后阶段**。只有在片段通过所有测试后，才会进入混合阶段。

## 2. 透明度处理方式一：Alpha 丢弃（Discard）

### 2.1 工作原理

在片段着色器中使用 `discard` 关键字，当 Alpha 值低于阈值时丢弃该片段。

```glsl
#version 330 core
out vec4 FragColor;
in vec2 TexCoord;
uniform sampler2D texture1;

void main()
{
    vec4 texColor = texture(texture1, TexCoord);
    if (texColor.a < 0.1)        // alpha < 0.1 → 丢弃
        discard;
    FragColor = texColor;
}
```

### 2.2 优缺点

| 优点 | 缺点 |
|------|------|
| 实现简单，只需在着色器中加一行 | 只能表示"全透明"或"全不透明" |
| 不影响深度缓冲区（丢弃的像素不写深度） | 无法表示"30% 透明"的效果 |
| 不需要排序 | 边缘可能有锯齿 |

### 2.3 边缘伪影问题

当纹理的环绕方式为 `GL_REPEAT`（默认值）时，纹理边缘会与对面的边缘进行插值采样，导致透明区域周围出现"有色光环"。

**解决方案**：将环绕方式设为 `GL_CLAMP_TO_EDGE`：

```cpp
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);
```

### 2.4 经典应用：草叶、植被

```cpp
// 绘制草地四边形（面朝摄像机，Billboarding）
discardShader.use();
for (auto& grass : grasses) {
    glm::mat4 model = glm::mat4(1.0f);
    model = glm::translate(model, grass.pos);
    // 旋转使四边形始终面朝摄像机
    model = glm::rotate(model, glm::radians(camYaw), glm::vec3(0, 1, 0));
    model = glm::scale(model, glm::vec3(scale));
    discardShader.setMat4("model", model);
    glDrawArrays(GL_TRIANGLES, 0, 6);
}
```

## 3. 透明度处理方式二：混合（Blending）

### 3.1 启用混合

```cpp
glEnable(GL_BLEND);
```

### 3.2 混合公式（默认 `GL_FUNC_ADD`）

```
Result = SourceColor × SourceFactor + DestinationColor × DestinationFactor
```

- `SourceColor`：当前片段的颜色
- `DestinationColor`：帧缓冲中已有的颜色
- `SourceFactor` / `DestinationFactor`：通过 `glBlendFunc` 设置

### 3.3 最常用的混合设置

```cpp
glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);
// SourceFactor = src.alpha
// DestinationFactor = 1 - src.alpha
// Result = src_color × alpha + dst_color × (1 - alpha)
```

**含义**：源的 alpha 越高，源的贡献越大；alpha=0.3 时，30% 来自源，70% 来自背景。

---

## 4. 混合函数详解

### 4.1 glBlendFunc(sfactor, dfactor)

```cpp
void glBlendFunc(GLenum sfactor, GLenum dfactor);
```

### 4.2 因子选项一览

| 选项 | 因子值 |
|------|--------|
| `GL_ZERO` | 因子 = 0 |
| `GL_ONE` | 因子 = 1 |
| `GL_SRC_COLOR` | 源的 RGB |
| `GL_ONE_MINUS_SRC_COLOR` | 1 - 源的 RGB |
| `GL_DST_COLOR` | 目标的 RGB |
| `GL_ONE_MINUS_DST_COLOR` | 1 - 目标的 RGB |
| `GL_SRC_ALPHA` | 源的 Alpha |
| `GL_ONE_MINUS_SRC_ALPHA` | 1 - 源的 Alpha |
| `GL_DST_ALPHA` | 目标的 Alpha |
| `GL_ONE_MINUS_DST_ALPHA` | 1 - 目标的 Alpha |
| `GL_CONSTANT_COLOR` | 通过 `glBlendColor()` 设置的常量颜色 |
| `GL_ONE_MINUS_CONSTANT_COLOR` | 1 - 常量颜色 |
| `GL_CONSTANT_ALPHA` | 通过 `glBlendColor()` 设置的常量 Alpha |
| `GL_ONE_MINUS_CONSTANT_ALPHA` | 1 - 常量 Alpha |

### 4.3 常用组合

```cpp
// 标准混合（半透明物体）
glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);

// 加法混合（粒子、发光效果）
glBlendFunc(GL_SRC_ALPHA, GL_ONE);

// 乘法混合（阴影、染色）
glBlendFunc(GL_DST_COLOR, GL_ZERO);
```

### 4.4 glBlendFuncSeparate — 分别设置 RGB 和 Alpha

```cpp
glBlendFuncSeparate(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA,  // RGB
                    GL_ONE, GL_ZERO);                       // Alpha
```

## 5. 混合方程

### 5.1 glBlendEquation(mode)

修改混合公式中的**运算符**（默认是加法）：

```cpp
void glBlendEquation(GLenum mode);
```

### 5.2 可用模式

| 模式 | 公式 |
|------|------|
| `GL_FUNC_ADD`（默认） | Result = Src × Sfactor + Dst × Dfactor |
| `GL_FUNC_SUBTRACT` | Result = Src × Sfactor - Dst × Dfactor |
| `GL_FUNC_REVERSE_SUBTRACT` | Result = Dst × Dfactor - Src × Sfactor |
| `GL_MIN` | Result = min(Src, Dst)（逐分量） |
| `GL_MAX` | Result = max(Src, Dst)（逐分量） |

## 6. 关键：透明物体的渲染顺序

这是混合最容易被忽略但**最重要的规则**。

### 6.1 问题

深度缓冲区不区分片段是否透明。如果先绘制近处的透明物体，深度缓冲区会记录近处物体的深度，导致远处的透明物体被深度测试丢弃。

```
错误顺序：近透明 → 远透明
  → 远透明被深度测试挡住 → 看不到远处的窗户
```

### 6.2 正确顺序

```
1. 绘制所有不透明物体（depth writes ON）
2. 对透明物体按距离排序（从远到近）
3. 关闭深度写入：glDepthMask(GL_FALSE)
4. 从远到近绘制透明物体
```

### 6.3 为什么从远到近？

```
混合公式：Result = src × alpha + dst × (1 - alpha)
```

`dst` 是**当前帧缓冲中已有的颜色**。远处的物体必须先画好，近处的才能在它上面叠加。

### 6.4 排序实现

```cpp
// 计算每个窗户到摄像机的距离
std::map<float, int> sorted;
for (int i = 0; i < NUM_WINDOWS; i++)
{
    float dist = glm::length(cameraPos - windows[i].pos);
    sorted[-dist] = i;  // 负数 key → 最远的在最前面
}

// 从远到近绘制
glDepthMask(GL_FALSE);  // 关闭深度写入！
for (auto& entry : sorted)
{
    int i = entry.second;
    DrawWindow(windows[i]);
}
glDepthMask(GL_TRUE);   // 恢复深度写入
```

### 6.5 关于 Discard 的排序

Alpha 丢弃 **不需要排序**。非丢弃的片段会正常写入深度缓冲区，丢弃的片段不写入任何东西，所以顺序不影响正确性。

## 7. 丢弃 vs 混合 — 场景决策表

| 场景 | 使用 Discard | 使用 Blending | 原因 |
|------|:-----------:|:-----------:|------|
| 草叶纹理（有透明边缘） | ✅ | ❌ | 只需要"有/无"，半透明无意义 |
| 栅栏/铁丝网 | ✅ | ❌ | 只有全透明和全不透明 |
| 玻璃窗 | ❌ | ✅ | 需要看透到后面的物体 |
| 水面 | ❌ | ✅ | 半透明 + 颜色混合 |
| 粒子效果 | ❌ | ✅ | 发光 + 叠加 |
| 选中高亮 | ❌ | ✅ | 需要半透明叠加 |
| UI 元素 | ❌ | ✅ | 淡入淡出效果 |

## 8. Demo 操作指南

### 8.1 键盘控制

| 按键 | 功能 |
|------|------|
| `ESC` | 退出程序 |
| `WASD` / 方向键 | 前后左右移动摄像机 |
| 右键拖动 | 旋转视角 |
| `B` | 切换混合 开/关（观察窗户从半透明变为不透明） |
| `G` | 切换草地显示（观察 discard 效果） |
| `M` | 切换混合方程（ADD / SUBTRACT / REVERSE） |
| 鼠标滚轮 | 调整窗户透明度（0.1 ~ 1.0） |
| `Tab` | 显示/隐藏 ImGui 调试面板 |

### 8.2 ImGui 面板

- **Blending**: 启用/禁用混合、当前混合函数
- **Blend Settings**: 混合方程选择器、透明度滑块
- **Windows**: 显示排序结果（从远到近的实际渲染顺序）
- **Vegetation**: 草地显示开关、discard 说明
- **Rendering Order**: 当前渲染顺序说明

### 8.3 学习建议

1. **`B` 关闭混合** → 窗户变得完全不透明（无视 alpha）→ 理解混合的作用
2. **`M` 切换 SUBTRACT** → 窗户颜色变为负色效果 → 理解混合方程
3. **移动摄像机到窗户后面** → 观察排序效果（远处的窗户在近处窗户后面也是可见的）
4. **`G` 关闭草地** → 只看透明窗户 → 聚焦混合理解
5. **滚轮调到 alpha=0.1** → 窗户几乎不可见 → 体验极低透明度
6. **滚轮调到 alpha=1.0** → 窗户完全覆盖背景 → 体验完全继承

## 9. 关键知识点总结

### 9.1 核心 API

```cpp
// 1. 启用混合
glEnable(GL_BLEND);

// 2. 设置混合因子
glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);

// 3. 设置混合方程（可选，默认 GL_FUNC_ADD）
glBlendEquation(GL_FUNC_ADD);

// 4. 透明物体渲染时必须关闭深度写入
glDepthMask(GL_FALSE);
//    ... 从远到近绘制透明物体 ...
glDepthMask(GL_TRUE);
```

### 9.2 渲染顺序口诀

```
不透明先画（深度写） → 透明排序（深度关） → 从远到近
```

### 9.3 与深度测试、模板测试的对比

| | 深度测试 | 模板测试 | 混合 |
|---|---------|---------|------|
| 位置 | 片段着色器后 | 片段着色器后（深度之前） | 管线最后 |
| 作用 | 丢弃被遮挡的片段 | 根据区域丢弃片段 | 合并片段颜色 |
| 默认 | 启用 | 禁用 | 禁用 |
| 经典应用 | 3D 场景 | 物体描边、镜面 | 透明度、玻璃 |
