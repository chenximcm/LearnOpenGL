## 1. 概述

**立方体贴图（Cubemap）** 是 OpenGL 高级部分第六章。它用 6 张 2D 纹理拼成一个"立方体"，通过一个 3D 方向向量来采样，广泛应用于天空盒、环境映射（反射/折射）等领域。

### 1.1 核心思路

```
6 张纹理 → 拼成立方体 → 用 3D 方向向量采样 → 模拟周围环境

 方向向量从立方体中心射出，击中哪个面就采样哪个面的纹理
```

### 1.2 三个主要应用

| 应用 | 说明 |
|------|------|
| **天空盒（Skybox）** | 用立方体贴图渲染场景背景，摄像机永远在中心 |
| **环境映射 — 反射** | 物体表面镜像反射周围环境 |
| **环境映射 — 折射** | 物体表面透过折射看到背后环境 |

## 2. 什么是立方体贴图

### 2.1 组成

6 个面，对应 OpenGL 的 6 个纹理目标：

```
GL_TEXTURE_CUBE_MAP_POSITIVE_X  →  右面 (+X)
GL_TEXTURE_CUBE_MAP_NEGATIVE_X  →  左面 (-X)
GL_TEXTURE_CUBE_MAP_POSITIVE_Y  →  顶面 (+Y)
GL_TEXTURE_CUBE_MAP_NEGATIVE_Y  →  底面 (-Y)
GL_TEXTURE_CUBE_MAP_POSITIVE_Z  →  前面 (+Z)
GL_TEXTURE_CUBE_MAP_NEGATIVE_Z  →  后面 (-Z)
```

### 2.2 采样方式

不同于 2D 纹理用 `(u, v)` 坐标采样，立方体贴图用 **3D 方向向量** 采样：

```glsl
uniform samplerCube skybox;
vec4 color = texture(skybox, directionVec3);
```

方向向量从立方体中心射出，OpenGL 自动判断它击中哪个面，并提取对应纹理坐标。

### 2.3 vs 普通 2D 纹理

| | 2D 纹理 | 立方体贴图 |
|---|---|---|
| 采样坐标 | `(u, v)` 2D | `(x, y, z)` 3D 方向 |
| 纹理目标 | `GL_TEXTURE_2D` | `GL_TEXTURE_CUBE_MAP` |
| 面数 | 1 | 6 |
| 典型用途 | 物体表面贴图 | 背景、反射 |

## 3. 创建立方体贴图

### 3.1 从文件加载（标准做法）

```cpp
unsigned int texID;
glGenTextures(1, &texID);
glBindTexture(GL_TEXTURE_CUBE_MAP, texID);

// 依次加载 6 个面的纹理
const char* faces[] = {
    "right.jpg", "left.jpg",
    "top.jpg",   "bottom.jpg",
    "front.jpg", "back.jpg"
};
GLenum targets[] = {
    GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X,
    GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y,
    GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z,
};

for (int i = 0; i < 6; i++) {
    int w, h, nrCh;
    unsigned char* data = stbi_load(faces[i], &w, &h, &nrCh, 0);
    glTexImage2D(targets[i], 0, GL_RGB, w, h, 0, GL_RGB, GL_UNSIGNED_BYTE, data);
    stbi_image_free(data);
}

glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);
glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_WRAP_R, GL_CLAMP_TO_EDGE);
```

### 3.2 程序化生成（Demo 中的做法）

为让 Demo 无需外部文件即可运行，每个面用一个纯色 + 渐变的简单图案：

```cpp
unsigned char* data = new unsigned char[size * size * 3];
for (int face = 0; face < 6; face++) {
    // 填充颜色数据...
    glTexImage2D(targets[face], 0, GL_RGB, size, size, 0, GL_RGB, GL_UNSIGNED_BYTE, data);
}
```

### 3.3 三个维度的环绕方式

立方体贴图多了一个维度 R：

```cpp
glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);
glTexParameteri(GL_TEXTURE_CUBE_MAP, GL_TEXTURE_WRAP_R, GL_CLAMP_TO_EDGE);  // ← 第三维
```

## 4. 天空盒（Skybox）

### 4.1 原理

天空盒是一个巨大的立方体，包裹整个场景，用立方体贴图渲染背景。

- 天空盒始终以**摄像机位置为中心**（移除 view 矩阵的平移分量）
- 天空盒在所有物体**之后（远处）**渲染

### 4.2 顶点着色器 — 两个关键技巧

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;
out vec3 TexCoords;             // ★ 输出 3D 方向向量

uniform mat4 projection;
uniform mat4 view;

void main()
{
    // ★ 技巧 1: 移除平移 — mat3(view) → mat4 丢弃平移列
    mat4 viewNoTranslation = mat4(mat3(view));

    // ★ 技巧 2: z = w — 始终渲染在远平面（最大深度）
    vec4 clipPos = projection * viewNoTranslation * vec4(aPos, 1.0);
    gl_Position = clipPos.xyww;

    TexCoords = aPos;  // 顶点位置 = 采样方向
}
```

#### 技巧 1: 移除平移

`mat4(mat3(view))` 将 view 矩阵转为 3×3（丢弃第 4 列平移分量），再转回 4×4。这样天空盒始终以摄像机为中心，不会"跟着摄像机走到外面去"。

```
有平移: 摄像机移动 → 天空盒不动 → 可能飞到天空盒外面
无平移: 摄像机移动 → 天空盒跟着移动 → 永远在中心
```

#### 技巧 2: `gl_Position = clipPos.xyww`

透视除法后 `z` 值 = `w/w` = 1.0，即深度缓冲的最大值。这意味着天空盒始终在"最远处"。

### 4.3 片段着色器

```glsl
#version 330 core
in  vec3 TexCoords;
out vec4 FragColor;

uniform samplerCube skybox;

void main()
{
    FragColor = texture(skybox, TexCoords);  // 用 3D 方向向量采样
}
```

### 4.4 渲染设置

```cpp
glDepthFunc(GL_LEQUAL);  // ★ 天空盒深度 = 1.0，用 LEQUAL 才能通过
skyboxShader.use();
// ... 设置矩阵 ...
glBindTexture(GL_TEXTURE_CUBE_MAP, cubemapTex);
glDrawArrays(GL_TRIANGLES, 0, 36);
glDepthFunc(GL_LESS);  // 恢复默认
```

默认 `GL_LESS` 要求 `新深度 < 旧深度` 才通过。天空盒深度 = 1.0（最大值），`GL_LESS` 下 `1.0 < 1.0` = false → 通不过。必须换成 `GL_LEQUAL`（`≤`）。

## 5. 环境映射 — 反射

### 5.1 原理

物体表面像镜子一样反射周围环境。本质上就是把"反射方向"当作 cubemap 的采样方向。

### 5.2 反射公式

```
视线方向 I = normalize(片段位置 - 摄像机位置)
法线 N      = normalize(法线)
反射方向 R  = reflect(I, N)  ← GLSL 内置函数
颜色        = texture(skybox, R)
```

```
        N
        ↑
    I ↗ │ ↘ R
  ──────●──────  表面
```

### 5.3 片段着色器

```glsl
#version 330 core
in  vec3 FragPos;
in  vec3 Normal;
out vec4 FragColor;

uniform vec3      cameraPos;
uniform samplerCube skybox;

void main()
{
    vec3 I = normalize(FragPos - cameraPos);   // 视线方向（片段 → 摄像机）
    vec3 R = reflect(I, normalize(Normal));     // 反射方向
    FragColor = vec4(texture(skybox, R).rgb, 1.0);
}
```

### 5.4 视觉效果

反射立方体表面"倒映"天空盒的颜色。立方体旋转时，反射画面也跟着变化——这就是环境映射的魅力。

## 6. 环境映射 — 折射

### 6.1 原理

光线从一种介质进入另一种介质时发生弯曲。用 `refract` 函数模拟。

### 6.2 折射公式

```
折射方向 R = refract(I, N, ratio)

ratio = 入射介质折射率 / 折射介质折射率
```

| 物质 | 折射率 | ratio (空气/物质) |
|------|--------|------------------|
| 空气 | 1.00 | — |
| 水 | 1.33 | 0.75 |
| 玻璃 | 1.52 | 0.658 |
| 钻石 | 2.42 | 0.413 |

### 6.3 片段着色器

```glsl
uniform float refractiveRatio;  // 默认 0.658（空气→玻璃）

void main()
{
    vec3 I = normalize(FragPos - cameraPos);
    vec3 R = refract(I, normalize(Normal), refractiveRatio);
    FragColor = vec4(texture(skybox, R).rgb, 1.0);
}
```

### 6.4 限制

`refract` 有临界角限制——当入射角超过临界角时，`refract` 返回 `vec3(0.0)`。这是正确的物理行为（全内反射），但可能让折射物体某些面变黑。

## 7. 天空盒渲染顺序的优化

### 7.1 为什么最后画天空盒？

```
先画天空盒 → 每个像素都要跑片段着色器 → 大部分被场景覆盖 → 浪费
最后画天空盒 → Early-Z 剔除被遮挡像素 → 只有边缘天空跑着色器 → 高效
```

### 7.2 Early-Z 原理

现代 GPU 在片段着色器之前先做深度测试（Early-Z）：

```
先渲染场景物体 → 深度缓冲已填满近处物体的深度值
再渲染天空盒   → Early-Z: 深度 = 1.0 → 大部分被近处物体拒绝 → 跳过着色器
```

## 8. Demo 操作指南

### 8.1 按键

| 按键 | 功能 |
|------|------|
| `ESC` | 退出 |
| `WASD` / 方向键 | 移动摄像机 |
| 右键拖动 | 旋转视角 |
| `1` | 天空盒 + 反射立方体 |
| `2` | 仅天空盒 |
| `3` | 天空盒 + 折射立方体 |
| `4` | 天空盒 + 反射 + 折射 |
| `Tab` | 调试面板 |

### 8.2 调试面板

- **Display Mode**：切换四种显示模式
- **Skybox / Floor**：开关天空盒和地板
- **Refractive Ratio**：调节折射率（滑块 0.5~1.0）

### 8.3 程序化天空盒

Demo 使用程序化生成的彩色立方体贴图（无需外部纹理），六个面各有不同颜色 + 十字线标记：
- 右 (+X)：红色
- 左 (-X)：绿色
- 顶 (+Y)：蓝色
- 底 (-Y)：黄色
- 前 (+Z)：青色
- 后 (-Z)：紫色

要使用真实照片级天空盒，下载教程提供的 6 张图片并修改 `createProceduralCubemap` 调用为文件加载即可。

## 9. 关键知识点总结

### 9.1 概念篇

| 概念 | 一句话 |
|------|--------|
| 立方体贴图 | 6 张 2D 纹理，用 3D 方向向量采样 |
| 天空盒 | 永远在摄像机中心的巨大立方体 |
| 环境映射 | 用 cubemap 模拟反射/折射 |
| `gl_Position.xyww` | 强制深度 = 1.0，渲染在远平面 |

### 9.2 API 篇

| API / GLSL | 说明 |
|------------|------|
| `GL_TEXTURE_CUBE_MAP` | cubemap 纹理目标 |
| `samplerCube` | GLSL 中 cubemap 采样器类型 |
| `texture(skybox, vec3)` | 用 3D 方向采样 cubemap |
| `reflect(I, N)` | GLSL 反射函数 |
| `refract(I, N, ratio)` | GLSL 折射函数 |
| `glDepthFunc(GL_LEQUAL)` | 天空盒深度 = 1.0，必须用 LEQUAL |

### 9.3 常见陷阱

| 陷阱 | 解决 |
|------|------|
| 天空盒跟着摄像机跑出场景 | 用 `mat4(mat3(view))` 移除平移 |
| 天空盒不显示 | 检查 `glDepthFunc(GL_LEQUAL)`，默认 `GL_LESS` 通不过 |
| 天空盒面之间有接缝 | 用 `GL_CLAMP_TO_EDGE` 作为环绕方式 |
| 折射物体某些面变黑 | 入射角超过临界角 → `refract` 返回 0 → 全内反射 |

## 10. 下一步 / 预告

立方体贴图是很多高级技术的基础：

- **动态环境映射**：每帧渲染周围场景到 cubemap，实现实时反射
- **阴影映射**：用深度贴图实现动态阴影
- **泛光（Bloom）**：后处理实现发光效果
- **延迟渲染（Deferred Shading）**：多渲染目标实现大量光源

下一章将学习 **高级数据**——缓冲区的高级用法和更灵活的渲染方式。
