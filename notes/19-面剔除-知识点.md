## 1. 概述

**面剔除（Face Culling）** 是 OpenGL 高级部分第四章——也是最简单、最有效率的渲染优化之一。

### 1.1 为什么需要？

在一个封闭的立方体中，你最多只能同时看到 3 个面，其余 3~5 个面背对着摄像机——画它们除了浪费 GPU 算力外毫无意义。

```
        ┌─────────┐
        │ 正面    │  ← 这些面朝向摄像机，需要画
        │ (可见)  │
   ──→  │         │
        │ 背面    │  ← 这些面背对摄像机，画了也看不见
        │ (不可见) │     → 用面剔除跳过它们！
        └─────────┘
```

### 1.2 在管线中的位置

```
顶点着色器 → 图元装配 → 面剔除 ← 在这里！ → 光栅化 → 片段着色器
```

面剔除发生在**图元装配之后、光栅化之前**。三角形在变成像素之前就被判定了"生死"——被剔除的图元不会进入光栅化和片段着色器，从而节省了大量计算。

## 2. 绕序（Winding Order）

### 2.1 什么是绕序？

当我们用 3 个顶点定义一个三角形时，顶点的**提交顺序**决定了它的"绕序"：

```
顶点顺序 A→B→C：
  B
  |\
  | \     从屏幕看向该三角形：
  |  \    逆时针 (CCW) = 正面 ← OpenGL 默认
  |   \
  A----C

顶点顺序 A→C→B：
  B
  |\
  | \     从屏幕看向该三角形：
  |  \    顺时针 (CW) = 背面
  |   \
  A----C
```

### 2.2 叉积判断

OpenGL 内部用**叉积**来判断绕序——取两条边的向量叉积得到法线方向，与视线方向比较即可判定正面/背面。

### 2.3 本项目的立方体

本项目的立方体使用 CCW 绕序（符合 OpenGL 默认），从外部看每个面都是 CCW → 正面。如果启用面剔除 (`GL_BACK`)，背向摄像机的面会被正确跳过。

## 3. 核心 API

### 3.1 启用/禁用

```cpp
glEnable(GL_CULL_FACE);   // 启用面剔除
glDisable(GL_CULL_FACE);  // 禁用它（所有面都画）
```

### 3.2 设置剔除哪一面

```cpp
glCullFace(GL_BACK);            // 剔除背面（默认、最常用）
glCullFace(GL_FRONT);           // 剔除正面（可以看到物体"内部"）
glCullFace(GL_FRONT_AND_BACK);  // 两个面都剔除（物体完全消失！）
```

### 3.3 设置哪个绕序算"正面"

```cpp
glFrontFace(GL_CCW);  // 逆时针 = 正面（默认）
glFrontFace(GL_CW);   // 顺时针 = 正面
```

### 3.4 组合效果

| `glCullFace` | `glFrontFace` | 效果 |
|:-----------:|:-------------:|------|
| `GL_BACK` | `GL_CCW` | 默认行为，剔除 CW 三角形 |
| `GL_BACK` | `GL_CW` | CW 三角形被当作背面剔除 → 如果你的模型用 CW 绕序，正面也能被看到 |
| `GL_FRONT` | `GL_CCW` | 剔除 CCW 三角形 → 看到物体**内部**（剖面效果） |
| `GL_FRONT_AND_BACK` | 任意 | 什么都不画 |

---

## 4. 为什么默认剔除背面？

1. **性能**：封闭物体的背面总是被正面遮挡的，画了也是浪费
2. **正确性**：剔除背面不影响最终画面——你本来也看不到背面
3. **节省片段着色器**：被剔除的三角形永远不会进入片段着色器，大大减少计算量

---

## 5. 实际应用场景

| 场景 | 是否启用 | 原因 |
|------|:------:|------|
| 封闭立方体、球体、角色模型 | ✅ | 背面不可见，剔除能节省 ~50% 片段 |
| 平面（地板、墙壁） | ✅ | 平面只有一面可见 |
| 半透明窗户（混合） | ❌ | 需要看到背面的窗户 |
| 草/树叶（discard） | ❌ | discard 的四边形两面都需要可见 |
| 开放几何体 | ❌ | 两面都可能被看到 |

## 6. 常见问题与调试

### 6.1 "物体消失了！"

最常见的面剔除调试问题——如果你导入了外部模型并且它"消失了"：

1. 检查是否启用了 `GL_CULL_FACE`
2. 检查 `glFrontFace` 是否匹配模型的绕序
3. 尝试 `glCullFace(GL_FRONT)` ——如果物体"出现"了，说明模型的绕序是反的
4. 如果上述都无效，暂时 `glDisable(GL_CULL_FACE)` 作为应急

### 6.2 线框调试

```cpp
glPolygonMode(GL_FRONT_AND_BACK, GL_LINE);  // 可以看到所有三角形的边
```
线框模式下你能看到哪些三角形被剔除了，哪些还在。

### 6.3 叉积验证绕序

对于给定顶点 A(ax,ay,az)、B(bx,by,bz)、C(cx,cy,cz)，要判断从摄像机方向看是 CCW 还是 CW：
- 计算 `(B-A) × (C-A)` 得到法线
- 如果法线指向摄像机 → 正面(CCW)
- 如果法线背离摄像机 → 背面(CW)

## 7. Demo 操作指南

| 按键 | 功能 |
|------|------|
| `F` | 切换面剔除 开/关 |
| `1` | 剔除模式：GL_BACK（默认） |
| `2` | 剔除模式：GL_FRONT（看内部） |
| `3` | 剔除模式：GL_FRONT_AND_BACK（全剔） |
| `R` | 切换绕序（CCW ↔ CW） |
| `Q` | 切换线框模式 |
| `G` | 显示/隐藏地板 |
| `Tab` | ImGui 面板 |

**学习建议**：按 `2` 剔除正面 → 看到立方体"内部"结构 → 理解背面的存在。再按 `Q` 开线框观察三角形方向。

---

## 8. 关键知识点总结

```
glEnable(GL_CULL_FACE)
       ↓
glCullFace(GL_BACK) ─── 剔除哪个面？
       ↓
glFrontFace(GL_CCW) ─── 哪个绕序算正面？
       ↓
只有通过这三步判断的三角形才会进入光栅化
```

**记忆口诀**："CCW 看正面，GL_BACK 除背面"——这是 99% 场景的默认配置。
