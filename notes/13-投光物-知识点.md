## 1. 三种光源类型概述

| 光源类型 | 模拟对象 | 关键参数 | 特点 |
|---------|---------|---------|------|
| **Directional**（方向光/平行光） | 太阳 | `direction` | 光线平行，全场景均匀，无衰减 |
| **Point**（点光源） | 灯泡 | `position` + `衰减系数` | 向所有方向发光，有距离衰减 |
| **Spotlight**（聚光灯） | 手电筒 | `position` + `direction` + `cutOff` | 锥体光照，边缘平滑过渡 |

### 核心区别

```
方向光：  → → → → → →    所有光线平行
点光源：  ↖ ↑ ↗            向所有方向发光
          ← ● →
          ↙ ↓ ↘
聚光灯：      ↖             锥体限制
            ● → ↗
            ↓
```

## 2. 方向光（Directional Light）

### 2.1 原理

方向光模拟距离无限远的光源（如太阳）。所有光线相互平行，光照方向不随片段位置变化。

### 2.2 计算

```cpp
// 方向光：所有片段使用相同的光照方向
vec3 lightDir = normalize(-light.direction);

// 方向光无衰减
float attenuation = 1.0;
```

> `-light.direction` 是因为 `light.direction` 定义的是光源指向的方向，我们需要从片段指向光源的方向。

### 2.3 特点

- 全场景**光照均匀**（靠近光源和远离光源的物体亮度相同）
- **无衰减计算**，效率高
- 没有「光源位置」，所以不需要光源标记立方体
- 典型应用：太阳光、月光

---

## 3. 点光源（Point Light）

### 3.1 原理

点光源模拟一个有限位置的光源（如灯泡）。光线从一点向所有方向发射，距离越远光照越弱。

### 3.2 计算

```cpp
// 点光源：方向因片段位置而异
vec3 lightDir = normalize(light.position - FragPos);

// 衰减：距离越远光照越弱
float distance = length(light.position - FragPos);
float attenuation = 1.0 / (k0 + k1 * d + k2 * d * d);
```

### 3.3 特点

- 每个片段计算**独立的光照方向**
- 有**距离衰减**（近亮远暗）
- 需要一个**小立方体标记光源位置**
- 典型应用：灯泡、火把、灯柱

---

## 4. 聚光灯（Spotlight）

### 4.1 原理

聚光灯模拟一个有限方向的光源（如手电筒）。在点光源的基础上增加锥体限制，只有锥体内的区域被照亮。

### 4.2 锥体检测

```cpp
// 判断片段是否在锥体内
float theta = dot(lightDir, normalize(-light.direction));
// 当 theta > cutOff 时，片段在锥体内

// 软边缘：从内锥到外锥平滑过渡
float epsilon = cutOff - outerCutOff;
float intensity = clamp((theta - outerCutOff) / epsilon, 0.0, 1.0);
```

### 4.3 参数说明

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `cutOff` | 内锥角余弦 | cos(12.5°) |
| `outerCutOff` | 外锥角余弦 | cos(17.5°) |

```
视角俯视图：
            ▓▓▓▓▓            ← outerCutOff 外锥边界
          ▓▓░░░░░▓▓          ← cutOff 内锥边界（全亮）
          ▓ ░░░░░ ▓
    ──────●──→───░──────    ← light.direction
          ▓ ░░░░░ ▓
          ▓▓░░░░░▓▓
            ▓▓▓▓▓

  cutOff 内：intensity = 1.0（全亮）
  outerCutOff 外：intensity = 0.0（全暗）
  之间：intensity 从 1.0 到 0.0 线性过渡
```

### 4.4 特点

- 有**方向性限制**（只在锥体内可见）
- 有**软边缘**（内外锥之间平滑过渡）
- 保持点光源的**距离衰减**
- 典型应用：手电筒、舞台聚光灯、车灯

## 5. 着色器中的统一处理

### 5.1 Light 结构体

三种光源类型共用一个 Light 结构体，不同字段按需使用：

```cpp
struct Light {
    // 所有类型共用
    vec3 ambient;
    vec3 diffuse;
    vec3 specular;

    // 方向光 / 聚光灯：方向
    vec3 direction;

    // 点光源 / 聚光灯：位置
    vec3 position;

    // 点光源 / 聚光灯：衰减系数
    float constant;
    float linear;
    float quadratic;

    // 聚光灯：锥体角度（余弦）
    float cutOff;
    float outerCutOff;
};
```

### 5.2 光照计算分支

```cpp
uniform int lightType;  // 0=方向光, 1=点光源, 2=聚光灯

void main()
{
    // ... 采样纹理、计算法线、视线方向 ...

    // 环境光（所有类型共用）
    vec3 ambient = light.ambient * diffuseMap;

    // 光源方向 + 衰减（因类型而异）
    vec3 lightDir;
    float attenuation = 1.0;

    if (lightType == 0) {
        // 方向光：平行光 + 无衰减
        lightDir = normalize(-light.direction);
    } else {
        // 点光源 / 聚光灯：位置相关 + 有衰减
        vec3 posToLight = light.position - FragPos;
        float distance = length(posToLight);
        lightDir = normalize(posToLight);
        attenuation = 1.0 / (constant + linear * d + quadratic * d²);
    }

    // 漫反射 + 镜面反射（所有类型相同）
    float diff = max(dot(norm, lightDir), 0.0);
    vec3 diffuse = light.diffuse * diff * diffuseMap;
    // ... specular ...

    // 聚光灯锥体限制
    float spotlightIntensity = 1.0;
    if (lightType == 2) {
        float theta = dot(lightDir, normalize(-light.direction));
        float epsilon = cutOff - outerCutOff;
        spotlightIntensity = clamp((theta - outerCutOff) / epsilon, 0.0, 1.0);
    }

    // 合成
    vec3 result = ambient + (diffuse + specular) * attenuation * spotlightIntensity;
}
```

## 6. 衰减（Attenuation）

### 6.1 公式

```
attenuation = 1.0 / (k0 + k1 × d + k2 × d²)

d  = 片段到光源的距离
k0 = constant（常数项）
k1 = linear（一次项）
k2 = quadratic（二次项）
```

### 6.2 参数选择

| 覆盖距离 | Constant | Linear | Quadratic |
|---------|----------|--------|-----------|
| 7 | 1.0 | 0.7 | 1.8 |
| 13 | 1.0 | 0.35 | 0.44 |
| 20 | 1.0 | 0.22 | 0.20 |
| 32 | 1.0 | 0.14 | 0.07 |
| 50 | 1.0 | 0.09 | 0.032 |
| 65 | 1.0 | 0.07 | 0.017 |
| 100 | 1.0 | 0.045 | 0.0075 |

- **距离越近**需要展示的场景 → 用更大的 linear/quadratic 值
- **距离越远**需要覆盖的场景 → 用更小的 linear/quadratic 值

### 6.3 衰减曲线

```
光照强度
   1.0 │  ●
       │    ●
       │      ●
       │        ●
       │          ●
       │            ●
       │              ●
   0.0 │________________●____
                          距离
```

### 6.4 为什么环境光不受衰减影响？

环境光代表**漫反射的环境光**——经过多次散射后的残余光线。即使距离光源很远，环境光仍然存在，所以不受衰减影响：

```cpp
vec3 result = ambient + (diffuse + specular) * attenuation * spotlightIntensity;
//            ↑ 环境光不受衰减影响
```

## 7. 聚光灯锥体（Spotlight Cone）

### 7.1 角度与余弦的关系

```cpp
// C++ 端（角度制 → 余弦值）
shader.setFloat("light.cutOff", cos(radians(12.5f)));

// GLSL 端（余弦值比较）
float theta = dot(lightDir, normalize(-light.direction));
// theta > cutOff  → 在锥体内
// theta < outerCutOff → 在锥体外
```

> 注意：角度越大，余弦值越小。所以 `cutOff > outerCutOff`（内角12.5°的余弦 > 外角17.5°的余弦）。

### 7.2 软边缘公式

```cpp
float epsilon = cutOff - outerCutOff;
float intensity = clamp((theta - outerCutOff) / epsilon, 0.0, 1.0);
```

当 `theta` 从 `cutOff` 变化到 `outerCutOff` 时，`intensity` 从 1 线性降低到 0。

## 9. 常见问题

### Q1：方向光为什么没有位置和衰减？

方向光模拟的是**无限远**的光源（太阳距离地球 1.5 亿公里）。

对方向光来说，场景中所有位置到光源的距离差可以忽略不计，所以：
- 所有光线平行 → 方向一致
- 距离差异忽略 → 无需衰减

这就是方向光效率高的原因——每个片段的 `lightDir` 都一样。

### Q2：为什么方向光也有 `light.direction` 而不是 `light.position`？

方向光的定义就是「所有光线平行」，所以我们只需要知道光从**哪个方向**照过来，而不是从**哪个点**发出。

```cpp
// 方向光
vec3 lightDir = normalize(-light.direction);
// ↑ 全场景相同，非常高效

// 点光源
vec3 lightDir = normalize(light.position - FragPos);
// ↑ 每个片段不同，需要逐像素计算
```

### Q3：聚光灯的 cutOff 为什么用余弦值而不用角度？

在着色器中，我们直接比较 `dot(lightDir, -light.direction)` 的结果，这个结果本身就是余弦值。

如果用角度，需要做 `acos()` 转换，这是一个开销较大的数学运算。对性能敏感的着色器来说，直接比较余弦值更高效。

所以 C++ 端预先算好 `cos(radians(angle))`，传给着色器直接比较。

### Q4：环境光为什么不受衰减和聚光灯影响？

这是有意为之的设计决策：

```cpp
vec3 result = ambient + (diffuse + specular) * attenuation * spotlightIntensity;
```

环境光模拟的是**间接光照**（经过环境多次散射后的残余光），即使没有直接光源照射，环境光也存在。

如果环境光也受衰减影响，那远离光源的物体会完全变黑，看起来不自然。

## 11. 关键知识点总结

### ✅ 需要掌握的

1. **三种光源类型**：方向光（平行/无衰减）、点光源（位置/衰减）、聚光灯（锥体/软边缘）
2. **衰减公式**：`1.0 / (k0 + k1·d + k2·d²)`
3. **聚光灯锥体**：用 `cutOff`（内锥）和 `outerCutOff`（外锥）实现软边缘
4. **角度 vs 余弦**：着色器中用余弦值，C++ 端做 `cos(radians())` 转换
5. **方向光无衰减**：所有光线平行，全场景光照均匀
6. **环境光独立**：不受衰减和聚光灯锥体影响
