## 1. 环境搭建

### 工具链

| 组件 | 选型 | 说明 |
|------|------|------|
| **语言** | C++17 | 现代 C++ 标准 |
| **图形 API** | OpenGL 3.3 Core Profile | 核心模式，弃用固定管线 |
| **窗口管理** | GLFW 3.x | 跨平台窗口和输入管理 |
| **OpenGL 加载器** | GLAD | 自动生成，加载 OpenGL 函数指针 |
| **构建工具** | Visual Studio 2022 | Windows 平台 |
| **系统** | Windows 11 + NVIDIA RTX 5080 | |

### 为什么需要 GLAD？

OpenGL 本质上只是一个 **规范（specification）**，具体实现由显卡驱动厂商提供。这意味着：

- OpenGL 函数地址在编译时未知，需要在 **运行时** 动态获取
- 不同平台、不同驱动获取函数指针的方式不同（Windows 用 `wglGetProcAddress`，Linux 用 `glXGetProcAddress`）
- **GLAD** 会自动检测当前平台，加载所有 OpenGL 函数指针，暴露为标准函数调用

> 💡 **一句话总结**：GLAD 让你能直接在代码里调用 `glGenVertexArrays()` 等 OpenGL 函数，而不用自己去搞平台相关的函数指针获取。

## 2. GLFW —— 窗口管理

### 2.1 初始化和配置

```cpp
glfwInit();
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);  // OpenGL 主版本号 3
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);  // OpenGL 次版本号 3 → 3.3
glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);  // 核心模式
```

| 函数 | 作用 |
|------|------|
| `glfwInit()` | 初始化 GLFW 库，**必须先调用** |
| `glfwWindowHint()` | 设置窗口/上下文提示（hint），在创建窗口前配置属性 |

### 2.2 核心模式 vs 立即模式

| 模式 | 说明 | 学习建议 |
|------|------|----------|
| **Core Profile**（核心模式） | 移除了所有弃用的固定管线 API，只保留现代着色器管线 | ✅ **推荐**，学习现代 OpenGL |
| **Compatibility Profile**（兼容模式） | 保留旧 API（如 `glBegin()` / `glEnd()`） | ❌ 不推荐，仅向后兼容 |
| **Forward Compatible**（向前兼容） | 移除被标记为弃用的功能 | macOS 上使用 Core Profile 时需开启 |

```cpp
// macOS 额外需要：
glfwWindowHint(GLFW_OPENGL_FORWARD_COMPAT, GL_TRUE);
```

### 2.3 创建窗口

```cpp
GLFWwindow* window = glfwCreateWindow(800, 600, "LearnOpenGL", NULL, NULL);
if (window == NULL)
{
    // 窗口创建失败，终止程序
    glfwTerminate();
    return -1;
}
glfwMakeContextCurrent(window);
```

| 参数 | 说明 |
|------|------|
| `800, 600` | 窗口的**宽**和**高**（像素） |
| `"LearnOpenGL"` | 窗口标题 |
| `NULL`（第三个） | 全屏模式显示器，`NULL` 为窗口模式 |
| `NULL`（第四个） | 共享资源的窗口，`NULL` 为不共享 |

> ⚠️ **重要**：创建窗口后必须调用 `glfwMakeContextCurrent(window)` 将 OpenGL 上下文绑定到当前线程。每个线程只能有一个当前上下文。

## 3. GLAD —— OpenGL 函数加载器

### 初始化

```cpp
if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress))
{
    std::cout << "Failed to initialize GLAD" << std::endl;
    return -1;
}
```

- `gladLoadGLLoader()` 接收一个函数指针获取器
- `glfwGetProcAddress` 是 GLFW 提供的函数，用于获取 OpenGL 扩展函数地址
- 初始化 GLAD 后，才能调用任何 OpenGL 函数

### 为什么 GLAD 要在 GLFW 之后初始化？

因为 GLAD 需要知道从哪里加载函数指针 —— 它依赖 **当前 OpenGL 上下文**。必须先创建窗口并使其上下文成为当前（`glfwMakeContextCurrent`），才能初始化 GLAD。

### 头文件包含顺序

```cpp
#include <glad/glad.h>       // 必须在 GLFW 之前
#define GLFW_INCLUDE_NONE    // 告诉 GLFW 不要包含 OpenGL 头文件
#include <GLFW/glfw3.h>
```

> 🔑 **关键**：`glad/glad.h` 必须在任何 OpenGL 头文件（包括 GLFW 引入的）**之前**包含。使用 `#define GLFW_INCLUDE_NONE` 防止 GLFW 自动引入 OpenGL 头文件，避免与 GLAD 冲突。

## 4. 视口与回调

### 4.1 设置视口

```cpp
glViewport(0, 0, 800, 600);
```

- 告诉 OpenGL 从哪个区域渲染窗口内容
- 参数：`(x, y, width, height)` — 左下角坐标和宽高
- 如果窗口比 800×600 大，OpenGL 只在这个区域内渲染

### 4.2 窗口大小变化回调

```cpp
void framebuffer_size_callback(GLFWwindow* window, int width, int height)
{
    glViewport(0, 0, width, height);
}

glfwSetFramebufferSizeCallback(window, framebuffer_size_callback);
```

- 用户调整窗口大小时，自动调用回调函数
- 确保视口始终与窗口大小匹配
- **帧缓冲大小** 可能不等于窗口大小（如 Retina 屏幕）

> 💡 **OpenGL 坐标系**：OpenGL 使用左下角为原点 (0, 0) 的坐标系，而窗口系统通常使用左上角为原点。

## 5. 渲染循环

```cpp
while (!glfwWindowShouldClose(window))
{
    glClear(GL_COLOR_BUFFER_BIT);
    glfwPollEvents();
    glfwSwapBuffers(window);
}
```

| 步骤 | 函数 | 作用 |
|------|------|------|
| **1️⃣ 检查** | `glfwWindowShouldClose()` | 检查窗口是否被关闭 |
| **2️⃣ 清屏** | `glClear(GL_COLOR_BUFFER_BIT)` | 清空颜色缓冲 |
| **3️⃣ 处理事件** | `glfwPollEvents()` | 处理键盘、鼠标等输入事件 |
| **4️⃣ 交换缓冲** | `glfwSwapBuffers()` | 交换前后缓冲，显示渲染内容 |

### 渲染循环的两种模式

| 模式 | 函数 | 行为 |
|------|------|------|
| **非阻塞** | `glfwPollEvents()` | 检查已发生的事件，处理完立即返回 |
| **阻塞等待** | `glfwWaitEvents()` | 一直等待直到有事件发生才返回（省 CPU） |

- 游戏通常用 `glfwPollEvents()` 保持高帧率
- 工具/UI 程序用 `glfwWaitEvents()` 省电

## 6. 双缓冲机制

### 为什么需要双缓冲？

- 如果程序直接绘制到屏幕，用户会看到 **逐像素绘制过程**（画面撕裂、闪烁）
- 解决方法：**双缓冲（Double Buffering）**

### 工作流程

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  后缓冲 (Back Buffer)         前缓冲 (Front Buffer)  │
│  ┌──────────────────┐        ┌──────────────────┐   │
│  │  在此处绘制       │  swap  │  显示给用户       │   │
│  │  下一帧内容       │ ─────→ │  当前帧内容       │   │
│  └──────────────────┘        └──────────────────┘   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- **后缓冲**：程序在其中绘制，用户看不到
- **前缓冲**：正在显示的内容
- `glfwSwapBuffers()`：交换前后缓冲，仅在 `vsync` 开启时等待垂直同步

### 垂直同步

```cpp
glfwSwapInterval(1);  // 开启垂直同步，锁定帧率到显示器刷新率（通常 60Hz/144Hz）
glfwSwapInterval(0);  // 关闭垂直同步，尽可能快（可能导致画面撕裂）
glfwSwapInterval(1);  // 开启垂直同步，限制帧率到显示器刷新率
```

## 7. 完整代码解读

```cpp
#include <glad/glad.h>
#define GLFW_INCLUDE_NONE
#include <GLFW/glfw3.h>
#include <iostream>

// 窗口大小变化时的回调函数
void framebuffer_size_callback(GLFWwindow* window, int width, int height)
{
    glViewport(0, 0, width, height);
}

int main()
{
    // ========== 1. 初始化 GLFW ==========
    glfwInit();
    glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
    glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
    glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);

    // ========== 2. 创建窗口 ==========
    GLFWwindow* window = glfwCreateWindow(800, 600, "LearnOpenGL", NULL, NULL);
    if (window == NULL)
    {
        std::cout << "Failed to create GLFW window" << std::endl;
        glfwTerminate();
        return -1;
    }
    glfwMakeContextCurrent(window);

    // ========== 3. 初始化 GLAD ==========
    if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress))
    {
        std::cout << "Failed to initialize GLAD" << std::endl;
        return -1;
    }

    // ========== 4. 设置视口 ==========
    glViewport(0, 0, 800, 600);
    glfwSetFramebufferSizeCallback(window, framebuffer_size_callback);

    // ========== 5. 设置清屏颜色 ==========
    glClearColor(0.2f, 0.3f, 0.3f, 1.0f);  // 深青色

    // ========== 6. 开启垂直同步 ==========
    glfwSwapInterval(1);

    // ========== 7. 渲染循环 ==========
    while (!glfwWindowShouldClose(window))
    {
        glClear(GL_COLOR_BUFFER_BIT);   // 用 glClearColor 设置的颜色清屏
        glfwPollEvents();                // 处理输入事件
        glfwSwapBuffers(window);         // 交换双缓冲
    }

    // ========== 8. 清理资源 ==========
    glfwTerminate();
    return 0;
}
```

### 执行流程

```
┌──────────────────────────────────┐
│         程序启动                  │
│              ↓                    │
│     glfwInit()                   │
│              ↓                    │
│     glfwWindowHint() × 3         │
│              ↓                    │
│     glfwCreateWindow()           │
│              ↓                    │
│     glfwMakeContextCurrent()      │
│              ↓                    │
│     gladLoadGLLoader()           │
│              ↓                    │
│     glViewport()                 │
│     glClearColor()               │
│              ↓                    │
│  ┌─────────────────────────┐     │
│  │  渲染循环                │     │
│  │  ├─ glfwWindowShouldClose│    │
│  │  ├─ glClear()           │     │
│  │  ├─ glfwPollEvents()    │     │
│  │  └─ glfwSwapBuffers()   │     │
│  └─────────────────────────┘     │
│              ↓                    │
│     glfwTerminate()              │
│              ↓                    │
│         程序退出                   │
└──────────────────────────────────┘
```

## 8. 关键知识点总结

### 🎯 核心概念

| 概念 | 要点 |
|------|------|
| **OpenGL 3.3 Core Profile** | 现代 OpenGL 起点，使用着色器管线，所有弃用 API 不可用 |
| **GLFW** | 窗口管理 + 输入处理 + OpenGL 上下文创建，跨平台 |
| **GLAD** | OpenGL 函数加载器，编译期不可知的函数地址在运行时加载 |
| **双缓冲** | 前缓冲显示、后缓冲绘制，`SwapBuffers` 交换避免画面撕裂 |
| **渲染循环** | 每帧：处理输入 → 绘制 → 交换缓冲，直到窗口关闭 |
| **视口 (Viewport)** | 定义 OpenGL 渲染到窗口的哪个区域 |

### ⚠️ 常见错误

```
❌ 忘记调用 glfwMakeContextCurrent()
   → GLAD 初始化失败，所有 OpenGL 调用无效

❌ glad.h 在 glfw3.h 之后包含
   → 编译报 OpenGL 函数重复定义

❌ 渲染循环内忘记调用 glfwPollEvents()
   → 窗口无响应，无法关闭

❌ 窗口关闭后忘记调用 glfwTerminate()
   → 资源泄漏

❌ 在 GLAD 初始化前调用 OpenGL 函数
   → 函数指针为空，程序崩溃
```

### 📚 初始化的标准流程（通用模板）

```
glfwInit()
    ↓
glfwWindowHint(...)       ← 配置 OpenGL 版本和模式
    ↓
glfwCreateWindow(...)     ← 创建窗口
    ↓
glfwMakeContextCurrent()  ← 绑定上下文
    ↓
gladLoadGLLoader(...)     ← 加载 OpenGL 函数
    ↓
glViewport(...)           ← 设置视口
    ↓
[其他 OpenGL 设置]        ← glClearColor 等
    ↓
while (!窗口关闭)          ← 渲染循环
    ↓
glfwTerminate()           ← 清理退出
```
