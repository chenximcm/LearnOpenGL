## 1. 概述

**深度测试**是 OpenGL 高级部分的第一章，虽然几乎所有 3D 渲染都需要它，但之前的章节只是简单地启用了 `glEnable(GL_DEPTH_TEST)`，没有深入探讨。

### 1.1 为什么需要深度测试？

| 没有深度测试 | 有深度测试 |
|---|---|
| 片段按照绘制顺序覆盖 | 片段根据深度值决定可见性 |
| 后绘制的物体始终覆盖先绘制的 | 离摄像机近的覆盖离摄像机远的 |
| 必须手动排序（油画算法） | 自动处理，无需排序 |

### 1.2 渲染管线中的位置

```
顶点着色器 → 几何着色器 → 光栅化 → 片段着色器 → → → 深度测试 → 混合 → 帧缓冲
                                                      ↑
                                                   深度缓冲区
```

深度测试发生在**片段着色器之后**、**混合（Blending）之前**。

## 2. 深度缓冲区（Depth Buffer）

### 2.1 核心概念

- 深度缓冲区（也叫 Z-Buffer）是一个与颜色缓冲区分辨率相同的二维数组
- 每个像素存储一个深度值（float，通常归一化到 [0, 1]）
- OpenGL 自动管理深度缓冲区（GLFW 创建窗口时自动分配）

### 2.2 深度值的非线性特性

深度值**不是线性**的：

| 区域 | 精度 | 原因 |
|---|---|---|
| 近平面附近 | 高 | 深度变化平缓，多个值可区分 |
| 远平面附近 | 低 | 多个不同 Z 值映射到相近的深度值 |

数学原因：透视投影矩阵中的 `z` 分量变换为：

```
depth = (far * (z + near)) / (z * (far - near))
```

这个非线性变换的副作用是：
- 近处物体深度值变化慢 → **精度高**
- 远处物体深度值变化快 → **精度低**

### 2.3 标准化深度（NDC）到线性深度的转换

```glsl
// 片段着色器中的转换
float ndc = depth * 2.0 - 1.0;
float linearDepth = (2.0 * near * far) / (far + near - ndc * (far - near));
float depthDisplay = linearDepth / far;  // 归一化到 [0, 1]
```

## 3. 深度测试函数（Depth Function）

### 3.1 glDepthFunc 参数

| 函数 | 通过条件 | 效果 |
|---|---|---|
| `GL_LESS`（默认） | 新深度 < 缓冲深度 | 标准：近的覆盖远的 |
| `GL_LEQUAL` | 新深度 ≤ 缓冲深度 | 类似 LESS，但对等深度也通过 |
| `GL_EQUAL` | 新深度 = 缓冲深度 | 仅精确匹配（需先填充缓冲） |
| `GL_NOTEQUAL` | 新深度 ≠ 缓冲深度 | 反向匹配 |
| `GL_GREATER` | 新深度 > 缓冲深度 | 反转效果：远的覆盖近的 |
| `GL_GEQUAL` | 新深度 ≥ 缓冲深度 | 类似 GREATER |
| `GL_ALWAYS` | 永远通过 | 无深度测试，等价于禁用 |
| `GL_NEVER` | 永不通过 | 什么都不显示 |

### 3.2 使用建议

- **默认 `GL_LESS`** 适用于绝大多数场景
- **`GL_LEQUAL`** 用于渲染天空盒等需要 "最远" 优先的场景
- **`GL_ALWAYS`** 可用于调试深度冲突，或渲染半透明对象
- **`GL_GREATER`** 可做负片效果等实验

## 4. 深度可视化

### 4.1 原理

通过在片段着色器中输出 `gl_FragCoord.z` 值，可以将深度缓冲区的信息可视化为灰度图：

```
颜色 = gl_FragCoord.z  →  近处暗（≈0），远处亮（≈1）
```

### 4.2 非线性 vs 线性

| 模式 | 效果 | 用途 |
|---|---|---|
| 非线性 | 近处细节丰富，远处一片白 | 展示深度的精度分布 |
| 线性 | 距离均匀映射到灰度 | 直观理解场景深度关系 |

## 5. 深度冲突（Z-fighting）

### 5.1 什么是 Z-fighting

当两个片段具有非常接近的深度值时，由于深度缓冲区的精度有限，会发生：

- 同一像素在两个深度值之间反复切换
- 产生剧烈的闪烁（看起来像两个面在 "打架"）
- 常见于大场景中两个非常接近的平面

### 5.2 解决方案

| 方法 | 说明 |
|---|---|
| **偏移（Polygon Offset）** | `glPolygonOffset` 为特定图元增加深度偏移 |
| **近/远平面调整** | 减小 far / 增大 near 可以提高整体精度 |
| **使用更高精度深度缓冲** | 默认 24 位，可升级到 32 位 |
| **避免重叠** | 在建模时避免两个面完全重合 |
| **尽早计算深度** | 在顶点着色器中输出深度（深度预渲染） |

### 5.3 Polygon Offset

```cpp
glEnable(GL_POLYGON_OFFSET_FILL);
glPolygonOffset(1.0f, 1.0f);  // factor, units
```

用于渲染轮廓线、贴花（Decal）等需要 "略高一点" 的场景。

## 6. Demo 操作指南

### 操作键位

| 键位 | 功能 |
|---|---|
| `W A S D` / `↑ ↓ ← →` | 摄像机前后左右移动 |
| `右键 + 拖动` | 旋转视角 |
| `D` | 切换深度测试 启用/禁用 |
| `F` | 循环切换深度函数 |
| `V` | 切换深度可视化模式 |
| `Tab` | 显示/隐藏 ImGui 调试面板 |
| `ESC` | 退出程序 |

### ImGui 面板功能

| 控制项 | 说明 |
|---|---|
| Enable Depth Test | 启用/禁用深度测试 |
| Depth Function | 下拉菜单选择 8 种深度函数 |
| Depth Visualization | 切换深度灰度图可视化 |
| Linearize Depth | 切换线性/非线性深度显示 |
| Z-Fighting Demo | 启用重叠平面演示深度冲突 |
| Offset | 调整重叠平面的间距 |

### 深度可视化解读

开启深度可视化（按 V）后，场景变为灰度图：

| 灰度值 | 含义 |
|---|---|
| 黑色（近） | 片段靠近摄像机 |
| 白色（远） | 片段远离摄像机 |
| 非线性模式 | 近处细节丰富（精度高），远处变化快 |
| 线性模式 | 均匀映射，直观展示距离 |

### 深度函数实验

尝试切换不同的深度函数，观察效果：

1. **GL_LESS** → 正常：近覆盖远
2. **GL_ALWAYS** → 无深度测试：后绘制的覆盖先绘制的
3. **GL_GREATER** → 反转：远覆盖近（负片效果）
4. **GL_NEVER** → 全黑：什么都不显示
