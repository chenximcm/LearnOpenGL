## 1. 纹理是什么

**纹理（Texture）** 本质上就是一张 **图片**。把它贴到 3D 物体的表面，能让物体看起来更真实。

```
裸模型（只有顶点颜色）          贴纹理后

  ┌──────────┐                 ┌──────────┐
  │          │                 │ 🧱🧱🧱  │
  │  纯色     │      → 贴纹理 → │ 🧱🧱🧱  │
  │  矩形     │                 │ 🧱🧱🧱  │
  └──────────┘                 └──────────┘
   单调的橙色                    一个容器（砖墙效果）
```

### 纹理在管线中的位置

在图形渲染管线中，纹理在 **片段着色器** 阶段被采样：

```
顶点数据 → 顶点着色器 → 图元组装 → 光栅化 → 片段着色器 ← 纹理
                                               ↓
                                         测试与混合
                                               ↓
                                            帧缓冲
```

顶点着色器的输出经过光栅化后，会为每个片段生成**插值后的纹理坐标**，片段着色器根据这个坐标去纹理图片中查找对应的颜色，这就是**纹理采样**。

## 2. 纹理坐标

### 2.1 什么是纹理坐标？

为了把纹理贴到物体上，需要为每个顶点指定一个**纹理坐标（Texture Coordinate，也叫 UV 坐标）**，告诉 OpenGL 纹理图片的哪个角落在该顶点位置。

```
纹理坐标系统：

   (0, 1) ┌──────────┐ (1, 1)
          │  ┌──────┐ │
          │  │ 纹理  │ │
          │  │ 图片  │ │
          │  └──────┘ │
   (0, 0) └──────────┘ (1, 0)

   ║ 范围：[0, 0]（左下） → [1, 1]（右上）
   ║ u（S）= 水平方向
   ║ v（T）= 垂直方向
```

### 2.2 矩形的纹理坐标映射

以矩形为例，4 个顶点的纹理坐标：

```
   (-0.5,  0.5)              (0.5,  0.5)
       左上  ① ─────────── ② 右上
            │             │
            │   矩形形状   │
            │             │
       左下  ③ ─────────── ④ 右下
   (-0.5, -0.5)              (0.5, -0.5)

   对应的纹理坐标：
   索引 3: 左上 (0, 1)       索引 0: 右上 (1, 1)
   索引 2: 左下 (0, 0)       索引 1: 右下 (1, 0)
```

### 2.3 顶点数据布局

**对比上一章，每个顶点从 3 个 float 变为 5 个 float：**

```
旧布局（仅位置）： [x] [y] [z]
新布局（位置+纹理）： [x] [y] [z] [u] [v]
```

```cpp
float vertices[] = {
    // 位置               // 纹理坐标
     0.5f,  0.5f, 0.0f,   1.0f, 1.0f,   // 右上
     0.5f, -0.5f, 0.0f,   1.0f, 0.0f,   // 右下
    -0.5f, -0.5f, 0.0f,   0.0f, 0.0f,   // 左下
    -0.5f,  0.5f, 0.0f,   0.0f, 1.0f    // 左上
};
```

### 2.4 更新顶点属性指针

因为顶点数据从 3 个 float 变成了 5 个 float，需要**新增一个顶点属性**：

```cpp
// 属性 0：顶点位置（vec3）
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE,
    5 * sizeof(float),           // stride = 20 字节
    (void*)0);                   // 偏移 = 0
glEnableVertexAttribArray(0);

// 属性 1：纹理坐标（vec2）★ 新增
glVertexAttribPointer(1, 2, GL_FLOAT, GL_FALSE,
    5 * sizeof(float),           // stride = 20 字节
    (void*)(3 * sizeof(float))); // 偏移 = 12 字节（跳过前 3 个 float）
glEnableVertexAttribArray(1);
```

```
内存布局（每个顶点 20 字节）：

 字节: 0    4    8    12   16
       | x  | y  | z  | u  | v  |    ← 顶点 0
       | x  | y  | z  | u  | v  |    ← 顶点 1
       | x  | y  | z  | u  | v  |    ← 顶点 2
       | x  | y  | z  | u  | v  |    ← 顶点 3
       ↑ stride = 20 字节

 属性 0：偏移 0，大小 3×float = 12 字节
 属性 1：偏移 12，大小 2×float = 8 字节
```

> ⚠️ **图片 Y 轴翻转**
> OpenGL 的纹理坐标原点在 **左下角**，但图片文件（JPEG/PNG）存储的原点在 **左上角**。所以加载纹理时需要垂直翻转，否则贴图是倒着的：
> ```cpp
> stbi_set_flip_vertically_on_load(true);
> ```

## 3. 纹理环绕方式

### 3.1 问题

当纹理坐标超出 [0, 1] 范围时，OpenGL 默认行为是什么？

### 3.2 四种环绕方式

| 环绕方式 | 效果 | 示意图 |
|---------|------|--------|
| `GL_REPEAT` | 🔄 **重复平铺**（默认） | `...` \| \| \| `...` |
| `GL_MIRRORED_REPEAT` | 🪞 **镜像重复** | `...` \| \| \| `...`（每次翻转） |
| `GL_CLAMP_TO_EDGE` | 🧱 **拉伸边缘像素** | `...` \| \| 颜色不变 |
| `GL_CLAMP_TO_BORDER` | 🖼️ **显示边框颜色** | `...` \| \| 显示设定的纯色 |

### 3.3 代码设置

```cpp
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_REPEAT);  // 水平方向（U）
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_REPEAT);  // 垂直方向（V）
```

> S = 水平方向（相当于 U / X），T = 垂直方向（相当于 V / Y）
>
> 如果使用 `GL_CLAMP_TO_BORDER`，还需要设置边框颜色：
> ```cpp
> float borderColor[] = { 1.0f, 1.0f, 0.0f, 1.0f };  // 黄色边框
> glTexParameterfv(GL_TEXTURE_2D, GL_TEXTURE_BORDER_COLOR, borderColor);
> ```

## 4. 纹理过滤

### 4.1 问题

当纹理在屏幕上被**放大**或**缩小**时，OpenGL 如何决定每个像素用纹理中的哪个纹素？

### 4.2 两种基本过滤方式

| 过滤方式 | 效果 | 适用场景 |
|---------|------|---------|
| `GL_LINEAR`（线性过滤） | 🎯 取最近的 4 个纹素的加权平均 | **平滑自然**，画面模糊 |
| `GL_NEAREST`（最近邻过滤） | 👾 取最近的 1 个纹素 | **像素风**，画面锯齿感 |

```
GL_LINEAR（双线性插值）          GL_NEAREST（最近邻）

  ■ ← 像素点                      ■ ← 像素点
  ┌──┬──┐                        ┌──┬──┐
  │  │  │                        │  │  │
  ├──┼──┤                        ├──┼──┤
  │  │  │                        │  │  │
  └──┴──┘                        └──┴──┘
  取周围 4 个纹素加权平均         取最近的 1 个纹素
```

### 4.3 两种应用场景

| 场景 | 参数常量 | 说明 |
|------|---------|------|
| **缩小**（MIN） | `GL_TEXTURE_MIN_FILTER` | 纹理比显示区域大时 |
| **放大**（MAG） | `GL_TEXTURE_MAG_FILTER` | 纹理比显示区域小时 |

```cpp
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
```

> ⚠️ **重要限制**：`GL_TEXTURE_MAG_FILTER` **不能**使用 Mipmap 相关的过滤选项（如 `GL_LINEAR_MIPMAP_LINEAR`），因为 Mipmap 只在纹理缩小时才有意义。

## 5. Mipmap —— 多级渐远纹理

### 5.1 为什么需要 Mipmap？

当物体远离相机时，纹理在屏幕上只占很少像素。如果继续用原始分辨率采样，会产生两个问题：

```
远处物体在屏幕上只占 2×2 像素
原始纹理是 512×512，采样频率严重不足！

结果：
  🔴 闪烁 —— 不同的像素在不同的帧被采样
  🔴 摩尔纹 —— 高频细节产生波纹状伪影
  🔴 性能浪费 —— 每帧都要读取大纹理，GPU 缓存命中率低
```

### 5.2 Mipmap 的原理

Mipmap 是一系列**逐级缩小的纹理**：

```
层级 0（原始）： 512 × 512
层级 1：         256 × 256  (1/2)
层级 2：         128 × 128  (1/4)
层级 3：          64 × 64   (1/8)
... 直到 1 × 1
```

OpenGL 自动根据像素在屏幕上的覆盖面积选择合适的层级采样。

```
屏幕上的物体很小 → 使用层级 3（64×64）
屏幕上的物体很大 → 使用层级 0（512×512）
```

### 5.3 生成 Mipmap

```cpp
glGenerateMipmap(GL_TEXTURE_2D);
```

这会在调用 `glTexImage2D` 之后执行，OpenGL 自动生成所有下级纹理。

### 5.4 Mipmap 过滤模式

| 模式 | 说明 | 效果 |
|------|------|------|
| `GL_NEAREST_MIPMAP_NEAREST` | 最近层级 + 最近邻采样 | 快，层间切换有突变 |
| `GL_LINEAR_MIPMAP_NEAREST` | 最近层级 + 线性采样 | 层内平滑，层间有突变 |
| `GL_NEAREST_MIPMAP_LINEAR` | 两层之间插值 + 最近邻 | 层间平滑过渡 |
| `GL_LINEAR_MIPMAP_LINEAR` | 两层之间插值 + 线性采样 | ✅ **三线性过滤，效果最好** |

> 🔑 **三线性过滤（`GL_LINEAR_MIPMAP_LINEAR`）** 是最常用的 Mipmap 过滤方式：先在两个最近层级内分别做双线性插值，再对两个结果做线性插值，所以叫「三线性」。

## 6. stb_image.h —— 图片加载库

### 6.1 简介

**stb_image.h** 是 Sean Barrett 开发的**单头文件图片加载库**，是 LearnOpenGL 教程推荐的图片加载方案。

优点：
- ✅ 单头文件 —— 只有 1 个 .h 文件，无需链接外部库
- ✅ 支持格式多 —— JPEG、PNG、BMP、GIF、PSD、HDR 等
- ✅ 零配置 —— `#define STB_IMAGE_IMPLEMENTATION` 即可使用

### 6.2 项目文件结构

```
vendor/include/stb_image.h    ← stb_image 头文件（声明 + 实现）
src/stb_image.cpp             ← 实现文件（只写 2 行）
```

```cpp
// src/stb_image.cpp —— 单独编译单元
#define STB_IMAGE_IMPLEMENTATION
#include "../vendor/include/stb_image.h"
```

> ⚠️ **为什么需要一个单独的 .cpp？**
> 单头文件库的原理：普通 include 只包含**声明**，`#define STB_IMAGE_IMPLEMENTATION` 展开**实现代码**。但实现代码只能在一个 .cpp 中展开一次，否则多处 include 会导致**重复定义**。新建 `stb_image.cpp` 就是为了做这件事。

### 6.3 加载图片

```cpp
#include "../vendor/include/stb_image.h"

int width, height, nrChannels;

// 翻转 Y 轴（OpenGL 原点在左下角，图片原点在左上角）
stbi_set_flip_vertically_on_load(true);

// 加载图片到 CPU 内存
unsigned char* data = stbi_load("textures/container.jpg",
                                &width, &height, &nrChannels, 0);
// data = 像素数据指针（RGB / RGBA）
// width / height = 图片宽高
// nrChannels = 颜色通道数（3 = RGB, 4 = RGBA）

// ... 上传到 GPU ...

// 释放 CPU 内存（数据已上传到 GPU）
stbi_image_free(data);
```

`stbi_load` 返回值说明：

| 图片格式 | nrChannels | format | 示例 |
|---------|-----------|--------|------|
| JPG | 3 | `GL_RGB` | `container.jpg` |
| PNG（无透明） | 3 | `GL_RGB` | — |
| PNG（有透明） | 4 | `GL_RGBA` | `awesomeface.png` |

## 7. 加载与创建纹理

### 7.1 完整流程

```cpp
unsigned int loadTexture(const char* path)
{
    unsigned int textureID;

    // 步骤 1：生成纹理对象
    glGenTextures(1, &textureID);

    // 步骤 2：绑定纹理
    glBindTexture(GL_TEXTURE_2D, textureID);

    // 步骤 3：设置纹理参数（包裹 + 过滤）
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_REPEAT);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_REPEAT);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);

    // 步骤 4：加载图片
    int width, height, nrChannels;
    unsigned char* data = stbi_load(path, &width, &height, &nrChannels, 0);

    if (data)
    {
        // 步骤 5：上传到 GPU
        GLenum format = (nrChannels == 4) ? GL_RGBA : GL_RGB;
        glTexImage2D(GL_TEXTURE_2D, 0, format,
                     width, height, 0, format,
                     GL_UNSIGNED_BYTE, data);

        // 步骤 6：生成 Mipmap
        glGenerateMipmap(GL_TEXTURE_2D);
    }

    // 步骤 7：释放 CPU 内存
    stbi_image_free(data);

    return textureID;
}
```

### 7.2 glTexImage2D 参数详解

```cpp
glTexImage2D(
    GL_TEXTURE_2D,          // 目标纹理类型
    0,                      // Mipmap 层级（0 = 基础层）
    GL_RGB / GL_RGBA,       // 内部格式（GPU 纹理的存储格式）
    width,                  // 图片宽度（像素）
    height,                 // 图片高度（像素）
    0,                      // 边框（必须为 0，历史遗留参数）
    GL_RGB / GL_RGBA,       // 输入格式（与 stbi_load 加载的通道数匹配）
    GL_UNSIGNED_BYTE,       // 数据类型（每个通道 1 字节）
    data                    // 像素数据指针
);
```

### 7.3 更新片段着色器

```glsl
#version 330 core
out vec4 FragColor;

in vec2 TexCoord;                         // 从顶点着色器传来的纹理坐标

uniform sampler2D ourTexture;              // 纹理采样器

void main()
{
    FragColor = texture(ourTexture, TexCoord);  // 采样纹理颜色
}
```

`texture(sampler, coord)` 是 GLSL 内置函数：

| 参数 | 类型 | 说明 |
|------|------|------|
| sampler | `sampler2D` | 绑定到某个纹理单元的采样器 |
| coord | `vec2` | 纹理坐标（会被自动插值） |
| 返回值 | `vec4` | RGBA 颜色值 |

## 8. 纹理单元

### 8.1 为什么需要纹理单元？

问题：片段着色器声明了两个 `sampler2D` 变量：

```glsl
uniform sampler2D texture1;
uniform sampler2D texture2;
```

但这两个变量只是「名字」，OpenGL 需要知道它们各自对应哪个纹理。**纹理单元就是连接 sampler2D 和具体纹理对象的桥梁。**

### 8.2 纹理单元的概念

```
纹理单元是纹理绑定的「插槽」：

                纹理单元 0          纹理单元 1
              ┌────────────┐     ┌────────────┐
   sampler    │ GL_TEXTURE0│     │ GL_TEXTURE1│
   "texture1" │            │     │            │
   ──────────→│  texture1  │     │  texture2  │
              │ (container)│     │(awesomeface)│
              └────────────┘     └────────────┘
```

OpenGL 规范至少保证 **80 个纹理单元**（`GL_TEXTURE0` ~ `GL_TEXTURE79`），至少 **16 个**。
纹理单元 0 是**默认激活**的，因此单纹理时可以省略 `glActiveTexture`。

### 8.3 使用纹理单元的完整流程

**初始化时**（告诉着色器每个 sampler 对应哪个纹理单元）：

```cpp
// 先激活着色器程序，再设置 uniform
shaderCombined.use();
shaderCombined.setInt("texture1", 0);   // texture1 → 纹理单元 0
shaderCombined.setInt("texture2", 1);   // texture2 → 纹理单元 1
```

**渲染循环中**（每帧绑定纹理到对应的纹理单元）：

```cpp
// 激活纹理单元 0，绑定 texture1
glActiveTexture(GL_TEXTURE0);
glBindTexture(GL_TEXTURE_2D, texture1);

// 激活纹理单元 1，绑定 texture2
glActiveTexture(GL_TEXTURE1);
glBindTexture(GL_TEXTURE_2D, texture2);
```

### 8.4 完整流程对应关系

```
C++ 代码                                     GLSL 着色器
──────────                                   ────────────
shader.setInt("texture1", 0);  ──────────→  uniform sampler2D texture1;  ← 纹理单元 0
shader.setInt("texture2", 1);  ──────────→  uniform sampler2D texture2;  ← 纹理单元 1

glActiveTexture(GL_TEXTURE0);
glBindTexture(GL_TEXTURE_2D, tex1);          texture() → texture1 → 单元 0 → tex1

glActiveTexture(GL_TEXTURE1);
glBindTexture(GL_TEXTURE_2D, tex2);          texture() → texture2 → 单元 1 → tex2
```

## 9. 双纹理混合

### 9.1 着色器实现

```glsl
#version 330 core
out vec4 FragColor;

in vec2 TexCoord;

uniform sampler2D texture1;
uniform sampler2D texture2;

void main()
{
    float mixValue = 0.2;  // 混合比例
    FragColor = mix(texture(texture1, TexCoord),
                    texture(texture2, TexCoord),
                    mixValue);
}
```

### 9.2 mix() 函数的数学原理

```
mix(a, b, t) = a * (1 - t) + b * t

当 t = 0.2 时：
  最终颜色 = texture1 * 0.8 + texture2 * 0.2
            ↑ container 占 80%     ↑ awesomeface 占 20%
```

| t 值 | 效果 |
|:----:|------|
| 0.0 | 完全显示 texture1 |
| 0.2 | 80% texture1 + 20% texture2（本章使用的效果） |
| 0.5 | 各占一半 |
| 1.0 | 完全显示 texture2 |

## 10. 完整流程回顾

### 初始化阶段

```
编译着色器                                       创建纹理
 │                                                 │
 ├─ Shader("vert", "frag", true)                   ├─ stbi_load() 加载图片
 │   ├─ 从文件读取 GLSL 源码                        ├─ glGenTextures()
 │   ├─ glCreateShader()                          ├─ glBindTexture()
 │   ├─ glCompileShader()                         ├─ glTexParameteri() 设置参数
 │   ├─ glLinkProgram()                           ├─ glTexImage2D() 上传到 GPU
 │   └─ glDeleteShader()                          └─ glGenerateMipmap()
 │       │                                               │
 │       └──── 创建 VAO/VBO ──── 设置顶点属性 ──── 设置纹理单元 ────┘
                                        │
                                  渲染循环
```

### 渲染循环（双纹理模式）

```
while (!glfwWindowShouldClose(window))
{
    glClear(GL_COLOR_BUFFER_BIT);

    shaderCombined.use();                         // 激活着色器

    glActiveTexture(GL_TEXTURE0);                 // 激活纹理单元 0
    glBindTexture(GL_TEXTURE_2D, texture1);       // 绑定纹理 1
    glActiveTexture(GL_TEXTURE1);                 // 激活纹理单元 1
    glBindTexture(GL_TEXTURE_2D, texture2);       // 绑定纹理 2

    glBindVertexArray(VAO);                       // 绑定 VAO
    glDrawElements(GL_TRIANGLES, 6,               // 索引绘制
                   GL_UNSIGNED_INT, 0);

    glfwSwapBuffers(window);                      // 交换缓冲
}
```

### 资源清理

```cpp
glDeleteVertexArrays(1, &VAO);
glDeleteBuffers(1, &VBO);
glDeleteBuffers(1, &EBO);
glDeleteTextures(1, &texture1);      // ★ 新增：删除纹理
glDeleteTextures(1, &texture2);
glfwTerminate();
```

## 11. 关键知识点总结

### 🎯 核心概念

| 概念 | 要点 |
|------|------|
| **纹理** | 贴到 3D 物体表面的 2D 图片 |
| **纹理坐标（UV）** | 范围 [0, 1]，每个顶点指定，光栅化时插值 |
| **纹理环绕** | `GL_REPEAT` 等 4 种方式控制 [0, 1] 外的纹理坐标行为 |
| **纹理过滤** | `GL_LINEAR` 平滑 / `GL_NEAREST` 像素风 |
| **Mipmap** | 多级渐远纹理，解决远处物体闪烁和性能问题 |
| **纹理单元** | 通过插槽机制让多个纹理同时工作 |
| **stb_image.h** | 单头文件图片加载库，替换旧版教程的 SOIL |
| **sampler2D** | GLSL 中的纹理采样器类型，用 `texture()` 函数采样 |

### 📦 新增 OpenGL 函数

| 函数 | 用途 | 本章首次出现 |
|------|------|------------|
| `glGenTextures()` | 生成纹理对象 ID | ✅ |
| `glBindTexture()` | 绑定纹理到 `GL_TEXTURE_2D` 目标 | ✅ |
| `glTexParameteri()` | 设置纹理参数（包裹/过滤） | ✅ |
| `glTexImage2D()` | 上传像素数据到 GPU 纹理 | ✅ |
| `glGenerateMipmap()` | 自动生成 Mipmap 层级 | ✅ |
| `glActiveTexture()` | 激活某个纹理单元 | ✅ |
| `glDeleteTextures()` | 删除纹理对象，释放 GPU 资源 | ✅ |

### 💡 最佳实践

```
纹理加载顺序（固定）：
glGenTextures(1, &id)
    ↓
glBindTexture(GL_TEXTURE_2D, id)
    ↓
glTexParameteri() × 4（设置参数）
    ↓
stbi_load() → glTexImage2D() → glGenerateMipmap()
    ↓
stbi_image_free(data)

纹理单元设置（双纹理）：
shader.setInt("texture1", 0)
shader.setInt("texture2", 1)

渲染循环中（每帧都需绑定）：
glActiveTexture(GL_TEXTURE0) → glBindTexture(GL_TEXTURE_2D, tex1)
glActiveTexture(GL_TEXTURE1) → glBindTexture(GL_TEXTURE_2D, tex2)
```

### ⚠️ 常见错误

```
❌ 忘记 #define STB_IMAGE_IMPLEMENTATION
   → 链接错误，找不到 stbi_load 等函数的实现
   ✅ 修复：新建 stb_image.cpp，在里面定义这个宏

❌ 把 STB_IMAGE_IMPLEMENTATION 写在了头文件里
   → 多个 .cpp include 后，重复定义
   ✅ 修复：只在唯一的 .cpp 中定义

❌ 忘记 glActiveTexture（多纹理时）
   → glBindTexture 默认绑定到 GL_TEXTURE0，texture2 永远是空的
   ✅ 修复：切换单元后再绑定

❌ 加载 PNG 透明图时用了 GL_RGB
   → 透明部分变黑
   ✅ 修复：检测通道数，用 GL_RGB 或 GL_RGBA

❌ 图片路径不对
   → stbi_load 返回 NULL
   ✅ 修复：路径相对于工作目录（VS 中默认是 .vcxproj 所在目录）

❌ 放大过滤器用了 Mipmap 选项
   → GL_INVALID_ENUM 错误
   ✅ 修复：glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, ...)
        只能使用 GL_LINEAR 或 GL_NEAREST
```
