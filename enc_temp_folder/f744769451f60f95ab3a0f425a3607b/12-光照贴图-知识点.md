## 1. 为什么需要光照贴图？

### 1.1 材质章节的局限

材质章节中，整个物体使用**统一的材质属性**：

```cpp
// 整个物体都是同样的颜色
material.diffuse  = vec3(0.5f, 0.0f, 0.0f);  // 统一红色
material.specular = vec3(0.7f, 0.6f, 0.6f);  // 统一高光
```

但现实世界的物体往往不同区域有不同的材质特性：

```
一个木箱：
  ┌─────────────────────┐
  │  █████████████████  │  ← 木板区域：漫反射有木纹，无高光
  │  ██  ┌─┐  ┌─┐  ██  │  ← 铁箍区域：漫反射为铁色，强高光
  │  ██  └─┘  └─┘  ██  │
  │  █████████████████  │
  └─────────────────────┘
```

### 1.2 光照贴图的解决方案

**光照贴图 = 用纹理（贴图）控制材质属性**

- **Diffuse Map**（漫反射贴图）→ 控制 `material.diffuse`
  - 就是平时说的「纹理贴图」
  - 物体不同位置显示不同的颜色

- **Specular Map**（高光贴图）→ 控制 `material.specular`
  - **白色** → 该区域高光强（金属、光滑表面）
  - **黑色** → 该区域无高光（木头、粗糙表面）

## 2. Diffuse Map（漫反射贴图）

### 2.1 本质

Diffuse Map = 普通的纹理贴图。告诉你物体每个位置「看起来是什么颜色」。

### 2.2 在管线中的位置

```
顶点着色器输出 TexCoord
       ↓
片段着色器采样 diffuseMap
       ↓
diffuse 分量 = light.diffuse × (diff × diffuseMap.rgb)
```

### 2.3 与纹理章节的关系

纹理章节我们只是简单地混合了两张纹理：
```cpp
FragColor = mix(texture(tex1, TexCoord), texture(tex2, TexCoord), 0.2);
```

现在，纹理采样结果参与到光照计算中：
```cpp
vec3 diffuseMap = vec3(texture(material.diffuse, TexCoord));
vec3 diffuse = light.diffuse * (diff * diffuseMap);
```

纹理不再只是贴上去的图案，而是**影响光照计算的输入参数**。

## 3. Specular Map（高光贴图）

### 3.1 本质

Specular Map 是一张**控制高光强度**的灰度图：

| 颜色 | 含义 | 示例材质 |
|------|------|---------|
| 白 (1.0, 1.0, 1.0) | 100% 镜面反射 | 金属、光滑塑料 |
| 灰 (0.5, 0.5, 0.5) | 50% 镜面反射 | 半粗糙表面 |
| 黑 (0.0, 0.0, 0.0) | 无镜面反射 | 木头、布料、橡胶 |

### 3.2 容器的高光贴图

`container2_specular.png` 的内容：
- 木纹部分：黑色 → 没有高光（木头是漫反射表面）
- 金属包角部分：白色 → 强高光（金属是光滑表面）

### 3.3 Specular Map 的计算

```cpp
vec3 specularMap = vec3(texture(material.specular, TexCoord));
vec3 specular = light.specular * (spec * specularMap);
//                                          ↑ 高光贴图控制每个片段的 specular 强度
```

## 4. 着色器变化

### 4.1 材质结构体的变化

**材质章节：**
```cpp
struct Material {
    vec3 ambient;       // uniform 颜色
    vec3 diffuse;       // uniform 颜色
    vec3 specular;      // uniform 颜色
    float shininess;
};
```

**光照贴图章节：**
```cpp
struct Material {
    sampler2D diffuse;      // 从纹理采样
    sampler2D specular;     // 从纹理采样
    float shininess;        // 仍为 uniform
};
```

`vec3` → `sampler2D`，从统一颜色变为逐像素纹理采样。

### 4.2 完整片段着色器

```cpp
#version 330 core
out vec4 FragColor;

in vec3 FragPos;
in vec3 Normal;
in vec2 TexCoord;

struct Material {
    sampler2D diffuse;
    sampler2D specular;
    float shininess;
};

struct Light {
    vec3 position;
    vec3 ambient;
    vec3 diffuse;
    vec3 specular;
};

uniform Material material;
uniform Light light;
uniform vec3 viewPos;

uniform bool useSpecularMap;
uniform vec3 specularOverride;

void main()
{
    // 从纹理采样
    vec3 diffuseMap  = vec3(texture(material.diffuse,  TexCoord));
    vec3 specularMap = vec3(texture(material.specular, TexCoord));

    // 环境光
    vec3 ambient = light.ambient * diffuseMap;

    // 漫反射
    vec3 norm = normalize(Normal);
    vec3 lightDir = normalize(light.position - FragPos);
    float diff = max(dot(norm, lightDir), 0.0);
    vec3 diffuse = light.diffuse * (diff * diffuseMap);

    // 镜面反射
    vec3 viewDir = normalize(viewPos - FragPos);
    vec3 reflectDir = reflect(-lightDir, norm);
    float spec = pow(max(dot(viewDir, reflectDir), 0.0), material.shininess);
    vec3 specMapValue = useSpecularMap ? specularMap : specularOverride;
    vec3 specular = light.specular * (spec * specMapValue);

    // 合成
    vec3 result = ambient + diffuse + specular;
    FragColor = vec4(result, 1.0);
}
```

## 5. C++ 代码变化

### 5.1 加载两张贴图

```cpp
unsigned int diffuseMap  = loadTexture("textures/container2.png");
unsigned int specularMap = loadTexture("textures/container2_specular.png");
```

### 5.2 设置纹理单元

```cpp
lightingShader.use();
lightingShader.setInt("material.diffuse",  0);  // GL_TEXTURE0
lightingShader.setInt("material.specular", 1);  // GL_TEXTURE1
```

### 5.3 每帧绑定纹理

```cpp
glActiveTexture(GL_TEXTURE0);
glBindTexture(GL_TEXTURE_2D, diffuseMap);
glActiveTexture(GL_TEXTURE1);
glBindTexture(GL_TEXTURE_2D, specularMap);
```

### 5.4 设置 sampler2D uniform

```cpp
// sampler2D 也是用 setInt 设置纹理单元编号
shader.setInt("material.diffuse", 0);   // unit 0
shader.setInt("material.specular", 1);  // unit 1
```

### 推荐尝试

1. **开关 "Use Specular Map"** — 观察高光贴图的效果差异：
   - 开启：只有金属包角有高光，木头部分无高光
   - 关闭：整个物体均匀高光（看起来像塑料）

2. **调整 Fallback Color** — 关闭高光贴图后，调节替代色从黑到白，观察高光强度的变化

3. **调节 Shininess** — 从 8 调到 256，观察高光范围的变化

## 7. 常见问题

### Q1：高光贴图为什么是灰度图？

Specular Map 本质只控制镜面反射的**强度**（0~1），不需要颜色信息。虽然 PNG 可以存储 RGB，但三个通道的值通常相同（灰色的 R=G=B）。

> 白 = 强度 1.0，灰 = 强度 0.5，黑 = 强度 0.0

有些高级用法可以在 specular map 的不同通道存储不同信息（R=高光强度，G=粗糙度，B=金属度），那就是后面 PBR 章节的事了。

### Q2：`material.ambient` 去哪了？

在光照贴图章节中，环境光的计算改为：

```cpp
vec3 ambient = light.ambient * diffuseMap;  // 用 diffuse map 代替 ambient
```

这是一种常用的简化：环境光也是从漫反射贴图采样，但乘上一个较暗的 `light.ambient` 系数。实际上更准确的做法是用一张独立的 ambient map（环境光遮蔽贴图），但为了简化教程这里跳过了。

### Q3：为什么纹理坐标 (TexCoord) 对光照贴图这么重要？

光照贴图需要正确的 UV 映射才能工作。

如果纹理坐标映射错误：
- Diffuse map：纹理显示错乱（图案不对）
- Specular map：高光出现在错误的位置（木头部分反光，金属部分不反光）

这就是为什么立方体需要每面 4 个顶点各自指定纹理坐标。

## 9. 关键知识点总结

### ✅ 需要掌握的

1. **光照贴图的核心思想**：用纹理替代 uniform 控制材质属性
2. **Diffuse Map**：控制物体不同区域的漫反射颜色（即普通纹理）
3. **Specular Map**：控制物体不同区域的镜面反射强度（白=强，黑=无）
4. **sampler2D**：材质结构体中的纹理类型，用 `setInt` 绑定纹理单元编号
5. **两个纹理单元**：`GL_TEXTURE0` 和 `GL_TEXTURE1` 分别绑定 diffuse 和 specular
6. **贴图对比实验**：开关高光贴图，观察木箱金属包角 vs 木板的高光差异

→ 摄像机 → 颜色 → 基础光照 → 材质 → 🎯 光照贴图
